Lua 怎么用

Lua 入口用来连接事件、定时器、焦点、实体和地形扩展。能用 JSON 的内容仍然优先写 JSON。

入口脚本结构

mod.json 里的 entry 指向入口脚本。脚本运行后返回一个表，引擎读取表里的生命周期函数。不需要实现全部四个——只写你需要的即可。

local M = {}

function M.on_load()
  engine.log.info("[copper_age] data loaded")
end

function M.on_world_init()
  engine.log.info("[copper_age] world is ready")
end

function M.on_tick(tick, dt)
end

function M.on_shutdown()
  engine.log.info("[copper_age] shutdown")
end

return M

四个生命周期函数的用途：

  • on_load —— 适合订阅事件、注册 焦点 条件、读取配置。此时数据已注册完毕，但世界还没生成。
  • on_world_init —— 适合生成世界相关内容、初始实体、注册 terrain biome/ore/feature。此时地形 API 已可用。
  • on_tick(tick, dt) —— 每帧执行。这个地方的逻辑要尽量轻，不要在每帧做大规模扫描。
  • on_shutdown —— 清理工作，比如写日志。

日志和配置

读取 MOD 配置时记得给第三个参数 fallback，避免旧配置缺字段时报错。

local debug_logs = engine.modding.get_setting("copper_age", "enable_debug_logs", false)

if debug_logs then
  engine.log.info("[copper_age] debug logging enabled")
end

创建和操作实体

如果在 data/entities 里写了实体原型，优先用 spawn_prototype。如果只是临时测试，也可以手动创建实体并逐个设置组件。

local id = engine.ecs.spawn_prototype("core:colonist")
if id ~= 0 then
  engine.ecs.set_position(id, 16, 65, 16)
  engine.ecs.set_name(id, "Copper Scout")
  engine.ecs.give_item(id, "copper_age:copper_ore", 4)
end

local hp = engine.ecs.get_health(id)
engine.log.info("health: " .. tostring(hp.current) .. "/" .. tostring(hp.max))

实体脚本数据

需要给实体挂任务状态、临时标记或脚本私有计数时，使用 engine.data 数据组件 API。它提供类似 NBT compound 的点分路径读写。完整说明见 数据组件 API。

engine.data.set(id, "quest.stage", 2)
engine.data.set(id, "quest.flags.met_elder", true)

local stage = engine.data.get(id, "quest.stage", 0)

合成和职业

配方和职业本体写在 JSON 里，Lua 只负责触发或响应结果。

local ok = engine.professions.assign(id, "core:worker", 1)
if ok and engine.crafting.craft(id, "core:wood_saw") then
  engine.log.info("crafted wood planks")
end

for _, recipe_id in ipairs(engine.crafting.list_recipes()) do
  local recipe = engine.crafting.get_recipe(recipe_id)
  if recipe then
    engine.log.info("recipe: " .. recipe.id .. " -> " .. recipe.output.id)
  end
end

工作池

发布工作时必须指定工作所属势力。faction_id 使用数据 ID 哈希，玩家/殖民地工作通常使用 core:player。AI 只会领取与自己势力一致的工作。

local player_faction = engine.util.data_id_hash("core:player")
local recipe_hash = engine.util.data_id_hash("core:craft_stick")
local job_id = engine.jobs.post("craft", player_faction, 16.5, 65.0, 16.5, 3.0, recipe_hash)

如果 AI 找不到通往已分配任务的寻路路径，该任务会解除 worker 绑定并回到工作池；该殖民者会在 100 tick 内跳过同一个任务实例，避免立刻重复承接。

如果 AI 在执行中被中断（例如崩溃状态或 AI 状态被外部清空），已申领但未完成的工作会自动解除 worker 绑定并回到工作池，之后可被同势力 AI 重新领取。

事件

订阅事件时保存返回的 handler id，之后可以取消订阅。优先用事件响应具体变化，不要在 on_tick 里反复扫描所有实体。

local handler = engine.events.subscribe("inventory:changed", function(evt)
  if evt.item_key == "copper_age:copper_ingot" then
    engine.log.info("copper ingot changed by " .. tostring(evt.delta))
  end
end, 10)

engine.events.unsubscribe("inventory:changed", handler)

引擎内置了七个事件，此外 CoreMod 的游戏系统也会发出自定义事件：

事件名payload 字段
inventory:changedentity_id, reason, item_id, item_key, delta
recipe:craftedentity_id, recipe_id, output_item_id, output_item_key, output_count
profession:assignedentity_id, profession_id, level
block:interactedentity_id, x, y, z, action_type, action
job:completedinstance_id, worker, type, category, faction_id, x, y, z, data, tick
focus:chosenfocus_id, instance_id, choice_id, choice_action, tick
focus:dismissedfocus_id, instance_id, tick

也可以用 engine.events.emit("name", payload) 发送自定义 Lua 事件。

装备系统

CoreMod 在 on_load 阶段注册了三个装备栏位：weapon（武器）、armor（护甲）、held_item（手持物品）。栏位通过 Lua API 注册，不使用 JSON 数据注册表。

-- 注册一个新栏位（通常在 on_load 中调用）
engine.equipment.register_slot("weapon")

-- 将物品装备到栏位（item_id 为 data ID 的哈希值）
engine.equipment.equip(entity_id, "held_item", item_hash, 1)

-- 从栏位卸下
engine.equipment.unequip(entity_id, "held_item")

-- 查询实体所有栏位
local eq = engine.equipment.get_equipment(entity_id)
engine.log.info("weapon: " .. tostring(eq.weapon.item_id))

-- 查询单个栏位
local held = engine.equipment.get_slot(entity_id, "held_item")
if held.item_id ~= 0 then
  engine.log.info("holding item: " .. tostring(held.item_id))
end

-- 检查栏位是否已注册
if engine.equipment.has_slot("weapon") then
  engine.log.info("weapon slot exists")
end

物品 ID 使用 engine.util.data_id_hash("core:wooden_sword") 格式的 FNV-1a 哈希值。

世界操作

对体素世界进行方块级别的操作。CoreMod 的挖矿、搬运、建造系统使用这些 API。

-- 移除方块
engine.world.remove_block(x, y, z)

-- 放置方块（block_id 为字符串如 "core:stone"）
engine.world.place_block(x, y, z, "core:stone")

-- 查询方块
local block = engine.world.get_block(x, y, z)
if block.exists then
  engine.log.info("block at (" .. x .. "," .. y .. "," .. z .. "): " .. block.id)
end

工具函数

-- 计算 data ID 的哈希值（用于物品/方块 ID 与 inventory/equipment 交互）
local hash = engine.util.data_id_hash("core:wooden_sword")

定时器

定时器按模拟 tick 执行，不是按真实时间。

engine.timers.after(20, function(tick)
  engine.log.info("runs once at tick " .. tostring(tick))
end)

local timer_id
timer_id = engine.timers.every(100, function(tick)
  engine.log.info("heartbeat " .. tostring(tick))
  if tick > 1000 then
    engine.timers.cancel(timer_id)
  end
end)

天气

天气由世界 seed、世界地图气候和模拟 tick 确定性推进。MOD 可以读取当前天气，用于作物、事件、音效或 UI 展示。

local weather = engine.weather.get()
if weather.precipitating then
  engine.log.info("weather: " .. weather.type .. " intensity=" .. tostring(weather.intensity))
end

确定性随机

math.random 在脚本环境中会报错——这是有意为之，确保跨平台和跨存档确定性。需要脚本随机数时使用 engine.random，它会在引擎初始化、新世界和读档时用世界 seed 重置。

local roll = engine.random.int(1, 100)
local chance = engine.random.float()

if engine.random.bool() then
  engine.log.info("rolled " .. tostring(roll) .. " chance=" .. tostring(chance))
end

engine.random.seed(42)
local debug_roll = engine.random.int(1, 6)

焦点

焦点 数据写在 data/focuses。Lua 可以注册条件、注册选项动作，也可以监听 焦点 被触发、选择或关闭。

engine.focus.register_condition("copper_age:has_copper", function(ctx)
  return ctx.tick >= 20
end)

engine.focus.register_choice_action("copper_age:accept", function(choice)
  engine.log.info("choice accepted: " .. choice.choice_id)
end)

engine.focus.subscribe(function(focus)
  engine.log.info("focus triggered: " .. focus.id)
end)

engine.events.subscribe("focus:chosen", function(evt)
  engine.log.info(evt.focus_id .. " -> " .. evt.choice_id)
end)

地形扩展

地形 API 通常在 on_world_init 使用。core 脚本里已经演示了注册 biome 和 ore 的方式；地物也可以通过 data/features 或 engine.terrain.register_feature() 注册。

function M.on_world_init()
  engine.terrain.register_ore({
    block = 12,
    noise_scale = 0.08,
    threshold = 0.55,
    min_y = 10,
    max_y = 60
  })

  local h = engine.terrain.height_at(0, 0)
  engine.log.info("height at origin: " .. tostring(h))
end

NPC 阵营

阵营定义和名称池优先写在 data/factions、data/name_pools。Lua 适合在事件发生时生成实例、修改关系或生成调试名称。

local faction = engine.factions.spawn("core:merchant_guild", 1234)
if faction.id ~= "" then
  engine.log.info("spawned faction: " .. faction.display_name)
  engine.factions.modify_relation(faction.id, 5)
end

local name = engine.factions.generate_name("${random_name} Guild", {"core:generic"}, 42)
engine.log.info("sample name: " .. name)

网络命令

网络 API 用于联机和命令同步。内容型 MOD 不建议把核心玩法依赖放在网络回调里。详情见网络同步。

if engine.network.is_connected() then
  engine.log.info("network mode: " .. engine.network.mode())
end

本地化

如果需要翻译 UI 文本，可以用 engine.locale 相关 API。翻译文件放在 lang/。

engine.locale.set_locale("zh_CN")
local text = engine.locale.t("ui.menu.start")
engine.log.info(engine.locale.get("ui", "menu.start"))
需要查函数签名时看 Lua API 速查。那一页有搜索框，适合用 focus、inventory、terrain 之类关键词快速过滤。
