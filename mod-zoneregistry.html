区域注册

区域类型（Zone Type）定义在 data/zones/ 下，以 JSON 描述。每种区域类型定义了名称和显示颜色。玩家在游戏中通过拖拽指定矩形的区域范围，系统根据区域类型决定该区域的用途——储存、种植、居住、收获等。

JSON 格式

{
    "id": "my_mod:workshop",
    "name": "Workshop Zone",
    "color": "#9B59B6"
}

字段说明

字段类型必填说明
idstring是唯一标识，格式 <mod_id>:<name>。
namestring否显示名称。省略时使用 id 作为名称。
colorstring否区域在地面上显示的颜色，使用十六进制颜色值（如 "#FF5500"）。省略时不显示高亮。
shapestring否区域维度："2d"（地面平面）或 "3d"（包含垂直范围）。默认 "2d"。
targetsstring[]否区域操作的目标类型。可选值："blocks"、"entities"、"items"、"features"。默认为空。
filterobject否目标过滤规则。键为目标类型（如 "blocks"），值为数据 ID 数组。仅匹配的方块/实体/物品会被纳入区域操作。
区域类型定义是轻量级的——只包含标识、名称和颜色。区域的具体行为（储存区放什么、种植区种什么）由 Lua 脚本通过事件系统和区域查询来处理，不写在 JSON 中。

内置区域类型

CoreMod 注册了 4 种区域类型：

区域ID颜色形状目标用途
储存区core:stockpile■ #8B73552ditems殖民者将物品搬运到此处集中存放。
种植区core:growing■ #4A7C3F2dblocks殖民者在此区域播种和管理作物。
居住区core:home■ #5B8BB43dentities指定殖民者的居住范围，殖民者会在此休息。
挖掘区core:mine■ #6E6A5E3dblocks3D 方块指定区，确认后为可挖方块发布挖掘工作。
伐木区core:chop■ #8A6F2A2dfeatures2D 地物指定区，确认后为树木地物发布伐木工作。

储存区 core:stockpile

最基本的区域类型。殖民者执行搬运任务时会将物品放到储存区内的空位上。多个储存区可以并排放置以扩大容量。

种植区 core:growing

殖民者会在种植区内的空农田方块上播种。配合作物定义和配方（如 wheat_seed_to_farmland）实现完整的种植流程。

居住区 core:home

定义殖民者的居住范围。殖民者在休息时会优先前往居住区内的床位。居住区也影响殖民者的心情和归属感。

区域实例

区域类型是定义，区域实例是运行时数据。每个区域实例包含：

  • 类型：引用某个区域类型定义。
  • 名称：玩家可以给每个区域实例起名字。
  • 形状：矩形（通过拖拽指定两角）或任意形状（通过逐个添加方块）。
  • 方块集合：区域内包含的所有方块坐标。
  • 设置：键值对形式的区域特定配置。

玩家拖拽指定 2D 区域时，区域实例保存的是被选中地面方块上方的可用空间层。例如在 Y=70 的方块上拖拽，区域坐标会落在 Y=71。脚本通过 engine.zone.create_rect 创建区域时仍使用传入的显式坐标。

拖拽预览和确认创建会按区域类型过滤不可用格子：储存区要求区域格为空且下方有方块支撑；种植区要求区域格为空且下方是土、草或农田。脚本可以调用 engine.zone.remove_cell(x, y, z) 删除区域中的单个格子，例如地面方块被挖掉时删除其上方的 2D 区域格。

Lua 集成

Lua 脚本可以通过 ECS 和事件系统与区域交互：

  • 查询某个坐标是否在某个区域内。
  • 获取某个区域的所有方块坐标。
  • 监听区域创建/删除事件。

挖掘指定

core:mine 是内置 3D 区域类型。底栏的挖掘按钮会进入 3D 拖拽指定模式；滚轮调整垂直范围，确认拖拽后会创建挖掘区域，并为选中的每个可挖实体方块向 WorkPool 发布一个 mine 工作。空气、水、岩浆、流体、植物材质和注册地物方块不会被加入挖掘任务。该工作使用 core:mine 方块动作，完成后会触发 block:interacted 并进入 CoreMod 挖掘系统，掉落来自方块 JSON 的 drops 字段。

伐木指定

core:chop 是内置 2D 区域类型。底栏的伐木按钮会进入地面拖拽指定模式；确认拖拽后会创建伐木区域，并为选中的每个匹配 core:chop_wood 方块动作的 core:tree 单体树地物向 WorkPool 发布一个工作。该工作完成后触发 block:interacted，由 CoreMod 的挖掘/采集系统移除整棵树，按 core:tree 的 drops 产出木材，并发出 block:chopped。

文件放置规则

  • 放在 data/zones/ 下，支持子目录。
  • 文件名随意，引擎只关心 JSON 内的 id 字段。

验证命令

在控制台（按 ~）中确认区域类型注册：

list_data zones                  -- 列出所有已注册的区域类型
data core:stockpile              -- 查看单个区域类型的完整 JSON
data core:chop                   -- 查看伐木指定区域类型
