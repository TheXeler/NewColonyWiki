配置文件

游戏使用三类配置文件：MOD 设置（mod.json 中的 settings）、核心控制台配置（权限和别名）、核心键位绑定。当前控制台配置和键位绑定只从运行目录的 mods/core/config/ 读取，第三方 MOD 的 config/ 不会自动合并。

MOD 设置

在 mod.json 的 settings 字段中声明默认值：

{
    "id": "copper_age",
    "settings": {
        "enable_debug_logs": false,
        "ore_spawn_rate": 1.0
    }
}

设置项支持字符串、数字和布尔值。玩家可以在 config/<mod_id>.json 中覆盖默认值，覆盖值的类型必须和默认值一致。

Lua 中读取设置：

local debug = engine.modding.get_setting("copper_age", "enable_debug_logs", false)
local rate  = engine.modding.get_setting("copper_age", "ore_spawn_rate", 1.0)

第三个参数是 fallback 值，防止旧配置缺字段时出错。详见 mod.json。

控制台权限

文件：mods/core/config/console_permissions.json

控制哪些控制台命令在什么权限等级下可用。

{
    "access_level": "developer",
    "command_permissions": {}
}

权限等级

等级说明
player普通玩家。只能使用最基本的命令。
modderMOD 开发者。可以使用 MOD 相关命令（mods、reload、list_data 等）。
developer开发者。可以使用所有命令，包括配置重载和快照。

命令权限覆盖

command_permissions 可以为单个命令指定不同于全局的权限等级：

{
    "access_level": "player",
    "command_permissions": {
        "mods": "player",
        "list_data": "player",
        "reload": "modder",
        "spawn_proto": "developer"
    }
}

未在 command_permissions 中列出的命令保留代码注册的默认权限；access_level 表示当前控制台会话拥有的权限等级，不是所有命令的默认权限。

控制台别名

文件：mods/core/config/console_aliases.json

为常用命令名创建快捷别名。别名目标必须是已经注册的命令名，不能包含参数或命令序列。

{
    "aliases": {
        "ld": "list_data",
        "proto": "spawn_proto"
    }
}

在控制台中输入别名等同于输入其目标命令，别名后面的参数会继续传给目标命令，例如 ld blocks prefix=core: 会执行 list_data blocks prefix=core:。加载别名前会注册内置别名：lsd、lr、lp、inv、ms、ems。

绑定条目格式

每个动作绑定一个数组，支持同时绑定多个输入。数组中的每个条目是一个独立的绑定。

类型type 值额外字段
键盘按键"key""key": 按键名称（见下表）
鼠标按键"mouse_button""button": 0=左键, 1=右键, 2=中键
滚轮"scroll""scroll_direction": 1=向上, -1=向下

按键名称

常见按键名称（不区分大小写）：

分类按键名称
字母A ~ Z
数字0 ~ 9
功能键F1 ~ F12
方向键UP、DOWN、LEFT、RIGHT
修饰键LEFT_SHIFT、RIGHT_SHIFT、LEFT_CONTROL、RIGHT_CONTROL、LEFT_ALT、RIGHT_ALT
特殊键SPACE、ENTER、ESCAPE、TAB、BACKSPACE、DELETE、INSERT
翻页PAGE_UP、PAGE_DOWN、HOME、END

可绑定的动作

动作名默认绑定说明
camera_orbit鼠标右键按住拖拽旋转视角
camera_zoom_in滚轮上沿视线方向前进
camera_zoom_out滚轮下沿视线方向后退
camera_move_forwardW镜头前进
camera_move_backwardS镜头后退
camera_move_leftA镜头左移
camera_move_rightD镜头右移
camera_move_upSpace镜头升高
camera_move_downLeft Shift镜头降低
select鼠标左键选择/交互
deselectEscape取消选择
toggle_pauseBackspace暂停/继续
set_speed_11游戏速度 1x
set_speed_22游戏速度 2x
set_speed_33游戏速度 3x
set_speed_44最快速度
toggle_debug_hudF3切换调试 HUD 显示
zone_operation_modifierCtrl区域操作辅助键，按住并滚轮可调整 3D 区域高度；持续 WASD 移动中按住可将镜头移速提升到 2 倍
一个动作可以绑定多个输入。例如可以同时绑定键盘和鼠标到同一个动作。键位绑定基于物理按键位置（scancode），因此无论键盘布局（QWERTY、AZERTY 等）或输入法状态如何，WASD 始终对应物理键位。可以在游戏内 Settings → Controls 页面直接点击按键进行重新绑定，修改会自动保存到配置文件；也可以手动编辑 JSON 文件。

config/ 目录放置

CoreMod 的运行配置文件放在 config/ 目录下：

my_mod/
  mod.json
  config/
    console_permissions.json    （可选）
    console_aliases.json        （可选）
    keybindings.json            （可选）

只有 CoreMod 的这些配置文件会在启动时自动加载。第三方 MOD 如果需要自定义运行配置，应使用 mod.json 的 settings 和玩家覆盖文件；不要期望自己的 config/console_aliases.json、config/console_permissions.json 或 config/keybindings.json 被自动合并。

验证和重载命令

在控制台中管理配置：

reload_config permissions         -- 重载控制台权限
reload_config aliases             -- 重载控制台别名
reload_config all                 -- 重载全部配置
validate_config permissions       -- 校验权限配置
validate_config aliases           -- 校验别名配置
mod_settings                      -- 查看所有 MOD 设置
validate_config aliases 只检查 JSON 结构和非空目标；真正应用别名时，如果目标不是已注册命令，控制台会忽略该别名并写入警告日志。
