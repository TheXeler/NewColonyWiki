作物注册

作物（Crop）定义在 data/crops/ 下，以 JSON 描述。每份作物定义了所需的农田类型、生长阶段、温度范围和收获产物。殖民者在种植区域中播种后，引擎根据作物配置自动推进生长阶段。

JSON 格式

{
    "id": "my_mod:tea_crop_data",
    "name": "Tea",
    "farmland_type": "my_mod:farmland",
    "growth_stages": [
        { "ticks": 800, "block": "my_mod:tea_crop" },
        { "ticks": 1000, "block": "my_mod:tea_crop" },
        { "ticks": 1200, "block": "my_mod:tea_crop" }
    ],
    "temperature": { "min": 12.0, "max": 32.0 },
    "outputs": [
        { "id": "my_mod:tea_leaves", "count": 3 },
        { "id": "my_mod:tea_seed", "count": 1 }
    ]
}

字段说明

字段类型必填说明
idstring是唯一标识，格式 <mod_id>:<name>。建议以 _crop_data 结尾以便区分。
namestring否显示名称。
farmland_typestring是所需农田方块的完整 ID。必须指向已注册的方块。常见值：core:farmland（旱地）、core:paddy（水田）。
growth_stagesarray是生长阶段数组，至少 1 个阶段。每个阶段包含 ticks 和 block。阶段按顺序推进，最后一个阶段结束后作物成熟可收获。
growth_stages[].ticksint是本阶段持续的游戏 tick 数（1 tick = 50ms，即 20 TPS）。例如 1200 ticks = 60 秒真实时间。
growth_stages[].blockstring否本阶段显示的方块 ID。必须指向已注册的方块。省略时保持上一阶段的方块不变。
temperatureobject是适宜温度范围。包含 min 和 max 两个浮点数（单位：度）。
temperature.minfloat是最低适宜温度。必须 ≤ max。
temperature.maxfloat是最高适宜温度。
outputsarray是收获产物列表，至少 1 个。每个产物包含 id 和 count。
outputs[].idstring是产物方块的完整 ID。必须指向已注册的方块。
outputs[].countint是产物数量，必须 > 0。
Tick 换算：游戏以 20 TPS 运行，即 1 秒 = 20 ticks。ticks: 1200 表示本阶段持续 1200 ÷ 20 = 60 秒真实时间。一个 3 阶段的作物如果每阶段 1200 ticks，总生长时间为 180 秒（3 分钟）。

农田类型

farmland_type 决定了作物能种在什么方块上。CoreMod 提供两种农田：

农田 ID说明适用作物
core:farmland普通旱地农田小麦、土豆、玉米、棉花、草药、南瓜、甘蔗
core:paddy水田（浸水农田）水稻

MOD 可以注册新的农田方块，只要在方块的 JSON 中正确定义，然后在作物的 farmland_type 中引用即可。

交叉引用校验

引擎在加载作物时会自动进行以下校验：

  • farmland_type 必须指向已注册的方块。
  • growth_stages[].block（如果填写）必须指向已注册的方块。
  • outputs[].id 必须指向已注册的方块。
  • 引用不存在的 ID 会导致加载报错并跳过该作物。

小麦 core:wheat_crop_data

基础粮食作物，3 阶段各 1200 ticks（共 180 秒）。适应温度范围宽，适合大多数群系种植。

土豆 core:potato_crop_data

耐寒作物，3 阶段共 2800 ticks（140 秒）。温度下限仅 5°C，是寒冷地区的首选作物。产量较高（3 个土豆）。

水稻 core:rice_crop_data

需要水田（core:paddy）的热带作物。3 阶段共 3000 ticks（150 秒）。温度下限 20°C，适合温暖群系。

玉米 core:corn_crop_data

高产作物但生长周期较长。3 阶段共 4200 ticks（210 秒）。温度范围 15~38°C，适合温带到热带。

棉花 core:cotton_crop_data

4 阶段的纤维作物，生长时间最长（4400 ticks = 220 秒）。产出棉花×3 用于纺织。

草药 core:herb_crop_data

生长最快的作物，仅 2 阶段共 1600 ticks（80 秒）。产出草药×3，适合快速轮作。

南瓜 core:pumpkin_crop_data

生长周期长但种子产出翻倍（种子×2）。3 阶段共 4500 ticks（225 秒）。

甘蔗 core:sugarcane_crop_data

4 阶段的热带作物，共 3200 ticks（160 秒）。温度上限高达 40°C。产出甘蔗×3。

生长与收获流程

  1. 播种：殖民者在种植区域（zone type = plant）的空闲农田方块上放置种子方块。
  2. 生长：引擎按 tick 计时，每经过 growth_stages[N].ticks 个 tick 后推进到下一阶段。阶段推进时替换为对应 block。
  3. 成熟：最后一个阶段结束后，作物标记为可收获状态。
  4. 收获：殖民者执行收获动作（core:harvest_crop），触发 block:interacted 事件。Lua 脚本监听此事件，根据 outputs 生成产物物品。

验证命令

在控制台（按 ~）中确认作物注册：

list_data crops                 -- 列出所有已注册的作物
data core:wheat_crop_data       -- 查看单个作物的完整 JSON
