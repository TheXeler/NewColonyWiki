地物注册

地物（Terrain Feature）是在地形装饰阶段放到地表上的小型方块装饰，例如石堆、灌木、遗迹碎片或可采集资源。地物可以通过 data/features/ JSON 自动注册，也可以在 Lua 中调用 engine.terrain.register_feature() 注册。

JSON 注册

把地物定义放在 data/features/ 下。加载器会递归扫描所有 .json 文件，在世界初始化时把它们注入地形生成器。

{
  "id": "my_mod:surface_stones",
  "block": "core:stone_chunk",
  "density": 1.5,
  "min_spacing": 1,
  "biomes": ["core:plains", "core:barren"]
}

Lua 注册

engine.terrain.register_feature({
    id = "my_mod:surface_stones",
    block = "core:stone_chunk", -- 也可以传数字方块 ID
    density = 1.5,
    min_spacing = 1,
    biomes = { "core:plains", "core:barren" },
})

字段说明

字段类型必填说明
idstring是唯一标识，格式为 <mod_id>:<name>。JSON 中省略前缀时会补当前 mod 前缀。
typestring否地物类型。当前支持 "tree"（树木）和默认的通用类型。设为 "tree" 时使用树类型专用字段。
blockstring 或 int通用类型必填要放置的方块。推荐使用数据 ID 字符串，例如 core:stone_chunk；需要兼容旧世界生成常量时也可以使用数字。
densityfloat是每个 chunk 的尝试生成密度。实际尝试次数约为 density * 6，必须大于 0。
min_spacingint否离 chunk 边缘的最小距离，默认 1。过大的值会被限制到安全范围。
biomesstring[]否允许生成的群系 ID 列表。省略或留空表示所有群系都可生成。

树类型地物

当 type 设为 "tree" 时，推荐使用 block 指向一个单体树地物方块。CoreMod 的树木生成 core:tree，伐木时一次性移除整棵树并按该方块的 drops 产出原木。旧的 trunk_block/leaves_block 组合仍可被引擎读取，但不再是 CoreMod 默认树木表现。

字段类型必填说明
typestring是必须为 "tree"。
blockstring 或 int推荐单体树地物方块 ID，如 "core:tree"。
trunk_blockstring 或 int兼容旧式树干方块 ID；仅在未提供 block 时使用。
leaves_blockstring 或 int兼容旧式树叶方块 ID；仅在未提供 block 时使用。
trunk_height_minint否旧式树干最小高度。
trunk_height_maxint否旧式树干最大高度。
leaves_radiusint否旧式树冠半径。
 
{
  "id": "core:forest_tree",
  "type": "tree",
  "block": "core:tree",
  "density": 2.0,
  "biomes": ["core:forest"]
}

生成规则

  • 地物只会放在当前群系的地表方块上方。
  • 目标位置上方必须在世界高度范围内。
  • 如果配置了 biomes，当前 chunk 的群系 ID 必须在列表中。
  • 同一个 id 再次注册会覆盖旧定义，方便 mod 在 Lua 中调整数据。

查询 API

local ids = engine.terrain.list_features()
local feature = engine.terrain.find_feature("my_mod:surface_stones")
engine.log.info("feature block = " .. tostring(feature.block))
data/features 会在每次新世界启动时重新注册。Lua 的 on_world_init 可以继续追加或覆盖这些地物定义。
