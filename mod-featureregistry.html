Wiki/地物注册

地物数据

地物由 C++ 世界生成器读取 data/features/*.json。Lua 不直接注册或替换地物定义；树苗生长通过 Server 的 engine.world.grow_tree 使用已加载树形整体提交。

当前状态

NCDOCS 定义了树木等世界部件应具有稳定实例 ID、明确体素集合和整体结算语义，但没有定义具体树形、生成密度、最小间距、温度范围或群落分布数值。

CoreMod 当前提供 core:oak，在平原与森林生成多方块橡树。其树形和密度用于当前实现，尚未作为正式平衡参数验收。每棵树包含 4 格树干和 49 格树叶；生成器先校验完整集合为空且位于当前区块内，再一次放置，避免截断树冠、覆盖现有浆果丛或与其他树共享单元。

{
  "id": "core:oak", "type": "tree",
  "block": "core:tree", "leaves_block": "core:leaves",
  "trunk_height": 4, "crown_radius": 2,
  "density": 0.65, "min_spacing": 5,
  "biomes": ["core:plains", "core:forest"],
  "temperature_optimum": 10.0, "temperature_range": 36.0
}

temperature_optimum 与 temperature_range 使用摄氏度口径（引擎气候范围为 -20 至 40），范围是三角衰减的半宽；两项均可省略，缺省为 4.0 与 36.0。树记录必须指定不同的树干 block 和已注册的 leaves_block。trunk_height 为 2 至 16 的整数，缺省 4；crown_radius 为 1 至 3 的整数，缺省 2。实际树间距不小于树冠直径加一。完整单元集合由 C++ 生成器提供，不根据相邻同类方块猜测归属。

只读接口

  • engine.terrain.list_features()：列出成功加载的地物 ID。
  • engine.terrain.get_feature(id)：读取已加载定义；不存在时返回空表。

engine.terrain.generated_tree_at(x,y,z) 返回该位置原生生成器提供的树归属、树干 hash 和逐格坐标/hash；已加载区块的树已改变时返回空。tree_cells(feature_id,x,y,z) 返回在指定根位置生长的完整形状。CoreMod 首次割除时将完整集合登记为带 UUID 的世界组件并保存，后续使用组件记录；树苗长成时登记同样的完整组件。生长提交失败会撤销预登记并保留树苗，成功后才发布组件变化通知，使监听器看到完整树形。
