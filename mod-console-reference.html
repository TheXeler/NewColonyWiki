控制台命令速查

按当前引擎命令注册表整理的表：命令、用法、默认权限、执行侧与说明。用搜索框过滤命令名、用法、权限或关键词。背景与工作流见 控制台命令。

命令分客户端与服务端两侧。help、相机、视图、选择、本地化、RML 重载、GPU 调试和连接管理命令由请求客户端执行；其余命令（包括只读查询）都会发送到服务端执行。没有可用服务端会话时世界命令明确失败，不会回退到客户端执行。
权限列是引擎注册表里的默认要求。没有显式权限条目的命令回退到 developer，所以标为 developer（默认） 的命令在普通模式服务端需要 config/console_permissions.json 显式放宽后才能执行；--DEBUG 启动的服务端本机与远程玩家默认都是 developer。别名先展开，再按目标命令检查权限。

说明

  • 本页只列出当前引擎实际注册的命令，与游戏内 help 的输出一致。help 是列出全部命令的唯一入口，分页大小上限 100。
  • 权限表中的 spawn、combat_test_arena 保留有条目，但当前引擎没有注册对应命令，执行会返回 Unknown console command。
  • =<lua code> 是前缀简写，先展开成 lua <code> 再检查权限与执行侧，所以它不会绕过 lua 的 developer 要求。
  • luafile / luacfile 只能执行已安装 MOD 的 scripts 目录下的 .lua 文件：绝对路径、盘符与 NTFS 流冒号、纯点号段（. / .. / ...），以及解析后落在该目录之外的符号链接都会被拒绝。
  • luac / luacfile 在请求客户端的 Lua VM 执行，不经过服务端；还没有创建世界时会报告客户端 Lua 运行时不可用。
  • doctor_*、diff_*snapshot*、*doctor_archives* 主要给引擎维护者使用，普通 MOD 作者不需要关心。
