UI 主题状态

旧的即时模式 UI 主题层已经从引擎和构建依赖中移除。当前主路线是游戏内 RmlUI，后续主题能力应通过 RML/RCSS 资源实现。

当前状态

UiTheme 仍保留一个轻量 API，用于避免旧配置和菜单状态在编译期断裂；它只扫描和记录主题文件，不再把任何样式应用到运行时渲染层。

后续重写项

  • 把全局 UI 颜色、间距、字号等样式迁移到 CoreMod/assets/ui/rml/*.rcss。
  • 为 RmlUI 文档设计可热重载的主题资源入口。
  • 清理旧主题配置文件或迁移为 RCSS 变量。
