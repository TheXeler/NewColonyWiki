群系注册

群系（Biome）通过 Lua 脚本调用 engine.terrain.register_biome() 注册。每个群系定义了地表方块、次地表方块、树木密度、是否生成洞穴和河流等属性。地形生成器在生成 chunk 时根据群系描述来决定地表材质和装饰物。

注册 API

engine.terrain.register_biome({
    id = "my_mod:wasteland",
    surface_block = 1,          -- 地表方块 ID
    subsurface_block = 1,       -- 次地表方块 ID
    weight = 1,                 -- 群系选择权重，必须为正整数
    subsurface_depth = 2,       -- 次地表深度（层）
    tree_density = 0.0,         -- 树木密度
    tree_trunk_min = 0,         -- 树干最矮高度
    tree_trunk_max = 0,         -- 树干最高高度
    tree_leaves_radius = 0,     -- 树冠半径
    trunk_block = 0,            -- 树干方块 ID
    leaves_block = 0,           -- 树叶方块 ID
    has_caves = false,          -- 是否生成洞穴
    has_rivers = false,         -- 是否生成河流
})

字段说明

字段类型必填说明
idstring是唯一标识，格式 <mod_id>:<name>。遵循标准 ID 规则。
surface_blockint是地表方块 ID。地形最顶层放置此方块。0 表示空气。
subsurface_blockint是次地表方块 ID。地表和基岩之间的填充层。
weightint否群系选择权重，必须为正整数，默认 1。值为 2 等价于在选择池中注册 2 次，约占总权重的 2 份。
subsurface_depthint否次地表深度（层数），默认 3。地表下方这么厚的层使用 subsurface_block。
tree_densityfloat否树木生成密度，默认 0。0 表示不生成树木，值越大树越多。
tree_trunk_minint否树干最小高度，默认 4。
tree_trunk_maxint否树干最大高度，默认 6。
tree_leaves_radiusint否树冠叶子半径，默认 2。
trunk_blockint否树干方块 ID。0 表示不生成树干。
leaves_blockint否树叶方块 ID。0 表示不生成树叶。
has_cavesbool否是否在此群系中生成洞穴，默认 true。
has_riversbool否是否在此群系中生成河流，默认 true。
tree_density、trunk_block、leaves_block 三者联动：只有当 tree_density > 0 且 trunk_block 和 leaves_block 都不为 0 时才会生成树木。如果群系不需要植被，将三者都设为 0 即可。

方块 ID 参考

方块 ID 是引擎分配的数字常量。CoreMod 中定义的方块对应如下：

常量名ID说明
Blocks.AIR0空气
Blocks.STONE1石头
Blocks.DIRT2泥土
Blocks.GRASS3草地
Blocks.WOOD4木头
Blocks.LEAVES5树叶
Blocks.CLAY10粘土

在 Lua 脚本中通过 require("worldgen.blocks") 引用这些常量。

内置群系

CoreMod 注册了 6 个内置群系，定义在 scripts/worldgen/biome_registry.lua 中：

群系ID地表次地表树木密度洞穴河流
平原core:plains草地泥土（3层）1.5是是
森林core:forest草地泥土（3层）5.0是是
荒地core:barren石头石头（1层）0是是
沼泽core:swamp泥土泥土（4层）2.0是是
海洋core:ocean水粘土（4层）0否否
河流core:river水粘土（2层）0否否

平原 core:plains

温和的草原群系，有稀疏的树木。地表为草地，下方是泥土层。适合殖民者定居和农业开垦。

  • 地表：草地，次地表：泥土（3 层）
  • 树木密度 1.5，树高 4~6，树冠半径 2
  • 每个 chunk 生成 0~3 棵树

森林 core:forest

密集的林地群系，树木高大且数量众多。提供丰富的木材资源。

  • 地表：草地，次地表：泥土（3 层）
  • 树木密度 5.0，树高 5~7，树冠半径 2
  • 每个 chunk 生成 5~10 棵树

荒地 core:barren

裸露的岩石地表，没有植被。资源匮乏但矿石暴露在表面，方便采集。

  • 地表：石头，次地表：石头（1 层）
  • 无树木、无植被

沼泽 core:swamp

泥泞的低洼群系，树木矮小稀疏。泥土层较深，适合挖掘粘土。

  • 地表：泥土，次地表：泥土（4 层）
  • 树木密度 2.0，树高 3~4，树冠半径 1（较小的树冠）
  • 每个 chunk 生成 1~4 棵树

海洋 core:ocean

大面积深水区域，底部覆盖粘土层。不适合定居或建造。海洋群系不会生成洞穴和河流。

  • 地表：水，次地表：粘土（4 层）
  • 无树木、无洞穴、无河流

河流 core:river

狭窄的水道，底床为粘土。河流群系的粘土层较薄。与海洋类似，不生成洞穴和河流。

  • 地表：水，次地表：粘土（2 层）
  • 无树木、无洞穴、无河流

群系选择机制

地形生成器使用确定性哈希算法为每个 chunk 选取群系：

  1. 将世界种子（seed）和 chunk 坐标（cx, cz）输入 FNV-1a 变体哈希函数。
  2. 累加所有群系的 weight 得到总权重，对哈希值取模后落入对应群系的权重区间。
  3. 相同种子和坐标总是选择同一个群系——世界是确定性可复现的。
weight 默认值为 1，必须是正整数。某群系的目标占比约为 该群系 weight / 所有群系 weight 总和；例如权重为 2 的群系等价于在选择池中注册了 2 次。

自定义群系 Lua 模块

除了调用 engine.terrain.register_biome() 注册 C++ 端数据，你还可以创建独立的 Lua 群系模块来定义 decorate() 函数。CoreMod 的做法是：

  1. 在 scripts/worldgen/biomes/ 下创建 Lua 文件，返回一个包含 id、surface_block、subsurface_block 和 decorate(data, surface_y, rng) 的表。
  2. 在 biome_registry.lua 中 require 并加入 _biomes 列表。

decorate() 函数签名：

function MyBiome.decorate(data, surface_y, rng)
    -- data: chunk 方块数据数组（一维）
    -- surface_y: 地表 Y 坐标
    -- rng: Xoshiro256 随机数生成器
    --   rng:next_int(min, max) 返回 [min, max] 范围内的随机整数
    -- 返回值: 放置的装饰物数量
    return 0
end

验证命令

在控制台（按 ~）中确认群系注册成功：

engine.terrain.list_biomes()   -- 返回所有已注册群系 ID 列表

或在 Lua 脚本中调用：

local biomes = engine.terrain.list_biomes()
for _, id in ipairs(biomes) do
    engine.log.info("Registered biome: " .. id)
end
