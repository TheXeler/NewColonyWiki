群系注册

群系（Biome）通过 Lua 脚本调用 engine.terrain.register_biome() 注册。每个群系定义了地表方块、次地表方块、树木密度、是否生成洞穴和河流等属性，以及偏好气候范围。地形生成器在生成 chunk 时根据对应位置的世界地图气候数据（温度、湿度、海拔）选择匹配的群系。

注册 API

engine.terrain.register_biome({
    id = "my_mod:wasteland",
    surface_block = 1,          -- 地表方块 ID
    subsurface_block = 1,       -- 次地表方块 ID
    weight = 1,                 -- 群系选择权重，必须为正整数
    subsurface_depth = 2,       -- 次地表深度（层）
    tree_density = 0.0,         -- 树木密度
    tree_trunk_min = 0,         -- 树干最矮高度
    tree_trunk_max = 0,         -- 树干最高高度
    tree_leaves_radius = 0,     -- 树冠半径
    trunk_block = 0,            -- 树干方块 ID
    leaves_block = 0,           -- 树叶方块 ID
    has_caves = false,          -- 是否生成洞穴
    has_rivers = false,         -- 是否生成河流
    climate = {                 -- 偏好气候范围（0..1）
        temperature_min = 0.0,  -- 最低温度偏好
        temperature_max = 1.0,  -- 最高温度偏好
        moisture_min = 0.0,     -- 最低湿度偏好
        moisture_max = 1.0,     -- 最高湿度偏好
        elevation_min = 0.0,    -- 最低海拔偏好
        elevation_max = 1.0,    -- 最高海拔偏好
    },
})

字段说明

字段类型必填说明
idstring是唯一标识，格式 <mod_id>:<name>。遵循标准 ID 规则。
surface_blockint是地表方块 ID。地形最顶层放置此方块。0 表示空气。
subsurface_blockint是次地表方块 ID。地表和基岩之间的填充层。
weightint否群系选择权重，必须为正整数，默认 1。在气候匹配的候选群系中按权重随机选取。
subsurface_depthint否次地表深度（层数），默认 3。地表下方这么厚的层使用 subsurface_block。
tree_densityfloat否树木生成密度，默认 0。0 表示不生成树木，值越大树越多。
tree_trunk_minint否树干最小高度，默认 4。
tree_trunk_maxint否树干最大高度，默认 6。
tree_leaves_radiusint否树冠叶子半径，默认 2。
trunk_blockint否树干方块 ID。0 表示不生成树干。
leaves_blockint否树叶方块 ID。0 表示不生成树叶。
has_cavesbool否是否在此群系中生成洞穴，默认 true。
has_riversbool否是否在此群系中生成河流，默认 true。
climatetable否偏好气候范围。省略或部分省略的字段默认为 0.0~1.0（匹配任何气候）。

气候子表字段

climate 表中的所有字段均为 float，取值范围 0..1。它们对应世界地图（WorldMap）中每个六边形格子的气候数据：

字段默认值含义
temperature_min0.0最低温度偏好。0 = 极寒。
temperature_max1.0最高温度偏好。1 = 酷热。
moisture_min0.0最低湿度偏好。0 = 干旱。
moisture_max1.0最高湿度偏好。1 = 潮湿。
elevation_min0.0最低海拔偏好。0 = 深海。
elevation_max1.0最高海拔偏好。1 = 山巅。
tree_density、trunk_block、leaves_block 三者联动：只有当 tree_density > 0 且 trunk_block 和 leaves_block 都不为 0 时才会生成树木。如果群系不需要植被，将三者都设为 0 即可。

方块 ID 参考

方块 ID 是引擎分配的数字常量。CoreMod 中定义的方块对应如下：

常量名ID说明
Blocks.AIR0空气
Blocks.STONE1石头
Blocks.DIRT2泥土
Blocks.GRASS3草地
Blocks.WOOD4木头
Blocks.LEAVES5树叶
Blocks.CLAY10粘土
Blocks.WATER12水

在 Lua 脚本中通过 require("worldgen.blocks") 引用这些常量。

平原 core:plains

温和的草原群系，偏好中等温度和中低湿度。地表为草地，下方是泥土层。适合殖民者定居和农业开垦。

  • 地表：草地，次地表：泥土（3 层）
  • 偏好温度 0.28–0.66，湿度 0.22–0.48
  • 稀疏树木（通过 feature 注册）

森林 core:forest

密集的林地群系，偏好温暖潮湿的气候。树木高大且数量众多，提供丰富的木材资源。

  • 地表：草地，次地表：泥土（3 层）
  • 偏好温度 0.28–1.0，湿度 0.48–1.0
  • 树木密度 5.0，树高 5~7，树冠半径 2

荒地 core:barren

裸露的岩石地表，偏好寒冷干燥的气候。没有植被。资源匮乏但矿石暴露在表面，方便采集。

  • 地表：石头，次地表：石头（1 层）
  • 偏好温度 0.0–0.50，湿度 0.0–0.30
  • 无树木、无植被

沼泽 core:swamp

泥泞的低洼群系，偏好温暖潮湿且低海拔的环境。树木矮小稀疏。泥土层较深，适合挖掘粘土。

  • 地表：泥土，次地表：泥土（4 层）
  • 偏好温度 0.35–1.0，湿度 0.55–1.0，海拔 0.0–0.55
  • 树木密度 2.0，树高 3~4，树冠半径 1

海洋 core:ocean

大面积深水区域，匹配低海拔的格子。底部覆盖粘土层。不适合定居或建造。海洋群系不会生成洞穴和河流。

  • 地表：水，次地表：粘土（4 层）
  • 海拔偏好 0.0–0.50
  • 无树木、无洞穴、无河流

河流 core:river

狭窄的水道，匹配略高于海洋的低海拔区域。底床为粘土。与海洋类似，不生成洞穴和河流。

  • 地表：水，次地表：粘土（2 层）
  • 海拔偏好 0.0–0.55
  • 无树木、无洞穴、无河流

群系选择机制

地形生成器为每个 chunk 选择群系时，使用以下流程：

  1. 根据 chunk 坐标 (cx, cz) 在世界地图中查找最近的六边形格子，获取该格子的温度、湿度、海拔。
  2. 在所有已注册群系中筛选气候匹配的候选集：温度、湿度、海拔均在群系的 climate 范围内。
  3. 对候选集按 weight 加权随机选取（使用世界种子和 chunk 坐标的确定性哈希，保证可复现）。
  4. 如果没有群系匹配当前气候（例如 mod 定义的气候范围有缺口），回退到从所有群系中按权重选取。
weight 默认值为 1，必须是正整数。在气候匹配的候选集中，某群系被选中的概率约为 该群系 weight / 候选集总 weight。不同群系的气候范围可以重叠——重叠区域内按权重随机选择，创造自然的过渡效果。
省略 climate 表的群系默认范围为 0.0–1.0（匹配任何气候），因此向后兼容：旧 mod 注册的群系仍然会出现在所有位置。

自定义群系 Lua 模块

除了调用 engine.terrain.register_biome() 注册 C++ 端数据，你还可以创建独立的 Lua 群系模块来定义 decorate() 函数。CoreMod 的做法是：

  1. 在 scripts/worldgen/biomes/ 下创建 Lua 文件，返回一个包含 id、surface_block、subsurface_block 和 decorate(data, surface_y, rng) 的表。
  2. 在 biome_registry.lua 中 require 并加入 _biomes 列表。

decorate() 函数签名：

function MyBiome.decorate(data, surface_y, rng)
    -- data: chunk 方块数据数组（一维）
    -- surface_y: 地表 Y 坐标
    -- rng: Xoshiro256 随机数生成器
    --   rng:next_int(min, max) 返回 [min, max] 范围内的随机整数
    -- 返回值: 放置的装饰物数量
    return 0
end

验证命令

在控制台（按 ~）中确认群系注册成功：

engine.terrain.list_biomes()   -- 返回所有已注册群系 ID 列表

或在 Lua 脚本中调用：

local biomes = engine.terrain.list_biomes()
for _, id in ipairs(biomes) do
    engine.log.info("Registered biome: " .. id)
end
