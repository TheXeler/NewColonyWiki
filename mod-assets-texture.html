Wiki/纹理格式

纹理格式

纹理放在 assets/textures/ 下。引擎通过 stb_image 读取 PNG，并把可用纹理拆成 16×16 tile 后加入运行时纹理图集。

支持的格式

格式扩展名说明
PNG.png唯一支持的纹理格式。支持 RGBA 通道。
纹理文件名建议只使用小写字母、数字和下划线。避免使用大写字母和特殊字符。不支持 JPG、BMP、TGA 等格式。

方块纹理

方块纹理放在 assets/textures/block/ 下。标准方块纹理尺寸为 16×16 像素。PNG 宽高必须是 16 的倍数，否则不会注册进图集。

assets/textures/block/
  dirt.png                   -- 16×16 方块贴图
  stone.png                  -- 16×16 方块贴图
  my_custom_block.png        -- 自定义方块贴图

物品纹理

物品图标纹理放在 assets/textures/item/ 下。

assets/textures/item/
  iron_ingot.png             -- 物品图标
  stone_chunk.png            -- 物品图标

多元素方块模型纹理

使用 Blockbench/Minecraft 风格模型的方块可以有更大的纹理图，通过模型 JSON 中的 texture_size 字段指定尺寸（如 64×64）。纹理仍会按 16×16 tile 切分，模型中的 UV 像素坐标会映射到对应 tile。详见 模型格式。

assets/textures/block/NewColonyTextures/
  grass.png                  -- 64×64 纹理图（配合 grass.json 模型使用）
  lantern.png                -- 配合 lantern.json 模型使用
assets/models/block/
  grass.json                 -- Blockbench 模型文件
  lantern.json               -- Blockbench 模型文件

实体纹理

实体纹理放在 assets/textures/entities/ 下。

assets/textures/entities/
  colonist.png               -- 殖民者贴图

图集打包

TextureAtlas::register_atlas_tiles 会把 PNG 按行优先拆成 prefix:0、prefix:1 等 tile。单个 tile 固定为 16×16 RGBA。

当前图集会包含程序化 terrain tile、CoreMod 的内置方块/模型纹理，以及实体原型引用到的实体贴图。通用“任意 MOD 方块模型自动接入”仍属于渲染层后续工作，不应当作稳定 API 承诺。

实体贴图图集

实体贴图由实体原型的 components.Visual.texture 引用。路径相对 MOD 的 assets/ 目录，例如 textures/entities/colonist.png。

实体贴图在世界资源初始化时拼入同一张运行时纹理图集。PNG 宽高必须是 16 的倍数；如果路径不存在或尺寸不合法，实体会继续渲染，但使用 missing texture。

"Visual": {
  "model": "biped",
  "texture": "textures/entities/colonist.png",
  "width": 0.45,
  "height": 1.80,
  "depth": 0.45
}
当前纹理图集是运行时生成资源，不是 MOD 需要提交的文件。不要把 generate/ 或 .spv/.model 等预处理产物当作源文件维护。
