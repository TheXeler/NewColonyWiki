Wiki/纹理格式

纹理格式

纹理放在 assets/textures/ 下。引擎只支持 PNG 格式，启动时自动将方块纹理打包到纹理图集（Texture Atlas）中。

支持的格式

格式扩展名说明
PNG.png唯一支持的纹理格式。支持 RGBA 通道。
纹理文件名只使用小写字母、数字和下划线。避免使用大写字母和特殊字符。不支持 JPG、BMP、TGA 等格式。

方块纹理

方块纹理放在 assets/textures/block/ 下。标准方块纹理尺寸为 16×16 像素，引擎会自动拼入图集。

assets/textures/block/
  dirt.png                   -- 16×16 方块贴图
  stone.png                  -- 16×16 方块贴图
  my_custom_block.png        -- 自定义方块贴图

物品纹理

物品图标纹理放在 assets/textures/item/ 下。

assets/textures/item/
  iron_ingot.png             -- 物品图标
  stone_chunk.png            -- 物品图标

多元素方块模型纹理

使用 Blockbench 模型的方块可以有更大的纹理图，通过模型 JSON 中的 texture_size 字段指定尺寸（如 64×64）。纹理内的像素坐标由模型 JSON 中的 UV 值引用。详见 模型格式。

assets/textures/block/NewColonyTextures/
  grass.png                  -- 64×64 纹理图（配合 grass.json 模型使用）
  lantern.png                -- 配合 lantern.json 模型使用
  grass.json                 -- Blockbench 模型文件
  lantern.json               -- Blockbench 模型文件

实体纹理

实体纹理放在 assets/textures/entities/ 下。

assets/textures/entities/
  colonist.png               -- 殖民者贴图

图集打包

引擎启动时自动扫描 assets/textures/block/ 下的所有 PNG 文件，将它们拼入一张大的纹理图集。每个 16×16 的方块纹理占图集中的一个 tile。多元素模型的纹理按 texture_size 分割为多个 tile。

MOD 不需要手动配置图集——只需把 PNG 放到正确目录，引擎会自动处理。

实体贴图图集

实体贴图由实体原型的 components.Visual.texture 引用。路径相对 MOD 的 assets/ 目录，例如 textures/entities/colonist.png。

实体贴图在世界资源初始化时拼入同一张运行时纹理图集。PNG 宽高必须是 16 的倍数；如果路径不存在或尺寸不合法，实体会继续渲染，但使用 missing texture。

"Visual": {
  "model": "biped",
  "texture": "textures/entities/colonist.png",
  "width": 0.45,
  "height": 1.70,
  "depth": 0.45
}
