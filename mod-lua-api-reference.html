Lua API 速查

按当前引擎绑定整理的函数表。用搜索框过滤模块、函数名、参数或说明。

API参数返回备注
engine.api.version()-string当前公共 MOD API 版本。
engine.api.compatible(version)stringbool判断请求的版本是否兼容。
engine.log.info(msg)string-写信息日志，自动加 Lua 标记。
engine.log.warn(msg)string-写警告日志。
engine.log.error(msg)string-写错误日志。
engine.time.tps属性number模拟每秒 tick 数（20）。
engine.time.dt属性number每 tick 的模拟时间间隔（0.05s）。
engine.random.seed(seed)integer-重置 Lua 确定性随机流。引擎初始化、新世界和读档时会用世界 seed 自动调用。
engine.random.float()-number返回 [0, 1) 范围内的确定性浮点数。
engine.random.int(min, max)integer, integerinteger返回闭区间 [min, max] 内的确定性整数；参数顺序反了会自动交换。
engine.random.bool()-bool返回确定性布尔值。
engine.ecs.create_entity()-entity id创建一个空实体。
engine.ecs.spawn_prototype(id)data identity id 或 0按 data/entities 原型创建实体。
engine.ecs.destroy_entity(entity)entity id-销毁实体。
engine.ecs.is_alive(entity)entity idbool实体是否还存在。
engine.ecs.entity_count()-number当前实体总数。
engine.ecs.has_component(entity, name)entity id, stringbool组件名用小写，如 position、health。
engine.ecs.set_position(entity, x, y, z)number, number, number-设置 Position 组件。
engine.ecs.get_position(entity)entity idtable返回 { x, y, z }，没有组件时返回空表。
engine.ecs.set_velocity(entity, x, y, z)number, number, number-设置 Velocity 组件。
engine.ecs.get_velocity(entity)entity idtable返回 { x, y, z }。
engine.ecs.set_rotation(entity, yaw, pitch)number, number-设置 Rotation 组件。
engine.ecs.get_rotation(entity)entity idtable返回 { yaw, pitch }。
engine.ecs.set_scale(entity, x, y, z)number, number, number-设置 Scale 组件。
engine.ecs.get_scale(entity)entity idtable返回 { x, y, z }。
engine.ecs.set_health(entity, current, max)integer, integer-设置 Health 组件。
engine.ecs.get_health(entity)entity idtable返回 { current, max }。
engine.ecs.set_needs(entity, hunger, fatigue, social)number, number, number-设置殖民者的三项需求。
engine.ecs.get_needs(entity)entity idtable返回 { hunger, fatigue, social }。
engine.ecs.set_name(entity, name)string-设置 Name 组件。
engine.ecs.get_name(entity)entity idstring没有 Name 时返回空字符串。
engine.ecs.add_colonist_tag(entity)entity id-给实体加上殖民者标记。
engine.ecs.has_colonist_tag(entity)entity idbool检查实体是否有殖民者标记。
engine.ecs.set_ai_state(entity, tree, lod)integer, integer-设置 AIState，current_node 置为 0。
engine.ecs.get_ai_state(entity)entity idtable返回 behavior_tree_id、current_node、lod_level。
engine.ecs.set_profession(entity, id, level)data id, integer-直接设置 Profession 组件，不检查职业规则。
engine.ecs.get_profession(entity)entity idtable返回哈希后的 profession_id 和 level。
engine.ecs.give_item(entity, id, count)data id, integerbool按物品堆叠上限加入库存，成功时触发 inventory:changed。
engine.ecs.get_inventory(entity)entity idtable返回原始 item_id 和 count。
engine.ecs.add_inventory_item(entity, item_id, count)hashed id, integerbool底层库存接口，不解析字符串 ID。
engine.ecs.remove_inventory_item(entity, item_id, count)hashed id, integerbool底层库存接口，数量不足时不删除。
engine.ecs.set_block_interactor(entity, x, y, z, action)integer...-设置方块交互意图并触发 block:interacted。action: 1=mine, 2=place, 3=interact。
engine.ecs.get_block_interactor(entity)entity idtable返回 x、y、z、action_type，没有组件时返回空表。
engine.ecs.set_prototype_ref(entity, id)entity id, data id-直接设置 PrototypeRef 组件。
engine.ecs.get_prototype_ref(entity)entity idstring读取 PrototypeRef；没有组件时返回空字符串。
engine.ecs.query_all_entities()-table返回所有实体 ID。
engine.ecs.query_colonists()-table返回有 Position 和 ColonistTag 的实体条目。
engine.ecs.query_with_position()-table返回有 Position 组件的实体条目。
engine.ecs.query_with_health()-table返回有 Health 组件的实体条目。
engine.ecs.add_equipment(entity)entity id-给实体添加 Equipment 组件（空装备栏）。
engine.ecs.has_equipment(entity)entity idbool实体是否有 Equipment 组件。
engine.modding.get_data_json(id)data idstring返回注册表中的原始 JSON，未找到时返回空字符串。
engine.modding.list_by_type(type)blocks 等table列出指定数据类型的全部 ID。
engine.modding.get_setting(mod, key, fallback)string, string, anyany读取配置，结合清单默认值和用户覆盖后的最终值。
engine.crafting.craft(entity, recipe)entity id, data idbool成功时扣除输入、添加输出，并触发库存和配方事件。
engine.crafting.list_recipes()-table列出已加载的配方 ID。
engine.professions.list()-table列出已加载的职业 ID。
engine.professions.can_assign(entity, profession)entity, data idbool检查实体是否满足转职条件。
engine.professions.assign(entity, profession, level)entity, data id, integer?bool分配职业，成功时触发 profession:assigned。
engine.events.subscribe(name, fn, priority)string, function, integer?handler idpriority 越大越早执行。
engine.events.unsubscribe(name, id)string, handler idbool取消订阅。
engine.events.clear(name)string-清空某事件的所有处理器。
engine.events.emit(name, payload)string, any-发送自定义 Lua 事件，不会进入 C++ 系统。
inventory:changed事件payload字段：entity_id、reason、item_id、item_key、delta。
recipe:crafted事件payload字段：entity_id、recipe_id、output_item_id、output_item_key、output_count。
profession:assigned事件payload字段：entity_id、profession_id、level。
block:interacted事件payload字段：entity_id、x、y、z、action_type、action。
focus:chosen事件payload字段：focus_id、instance_id、choice_id、choice_action、tick。
focus:dismissed事件payload字段：focus_id、instance_id、tick。
engine.timers.after(ticks, fn)integer, functiontimer id一次性定时器，回调参数为 tick、dt、timer_id。
engine.timers.every(ticks, fn)integer, functiontimer id重复定时器，ticks 为 0 时按 1 处理。
engine.timers.cancel(id)timer idbool取消定时器。
engine.timers.clear()--清空全部 Lua 定时器。
engine.focus.register_condition(name, fn)string, functionbool注册 Focus 条件，回调返回 bool。
engine.focus.register_choice_action(name, fn)string, functionbool注册 Focus 选项动作。
engine.focus.subscribe(fn)functionhandler id监听 Focus 触发通知。
engine.focus.unsubscribe(id)handler idbool取消 Focus 触发监听。
engine.focuses.list()-table列出 Focus 定义 ID。
engine.focuses.active()-table列出当前活跃的 Focus 实例和 choices。
engine.focuses.choose(instance, choice)instance id, stringbool执行选项动作并触发 focus:chosen。
engine.focuses.dismiss(instance)instance idbool关闭 Focus 并触发 focus:dismissed。
engine.inventory.hash(id)data idhashed id把字符串 ID 转为库存内部 ID。
engine.inventory.resolve(item_id)hashed idstring把库存内部 ID 转回数据 ID。
engine.inventory.inspect(entity)entity idtable返回 slot、item_id、id、count。
engine.factions.list_defs()-table列出已注册的 NPC 阵营定义 ID。
engine.factions.list_pools()-table列出已注册的名称池 ID。
engine.factions.spawn(def_id, seed)data id, integer?table生成阵营实例并返回 id、display_name、relation、max_relation、min_relation、spawned_tick。
engine.factions.get_instance(id)stringtable 或 nil读取已生成阵营实例。
engine.factions.list_instances()-table列出当前已生成的阵营实例。
engine.factions.modify_relation(id, delta)string, integerinteger调整关系值并返回调整后的关系；结果会按阵营定义限制范围。
engine.factions.generate_name(template, pools, seed)string, table?, integer?string按 ${random_name} 模板和可选名称池生成确定性名称。
engine.network.send_move(entity, x, y, z)entity, number, number, number-发送移动命令到网络层。
engine.network.send_build(x, y, z, block_id)integer, integer, integer, integer-发送建造方块命令。
engine.network.send_mine(x, y, z)integer, integer, integer-发送挖掘方块命令。
engine.network.send_profession(entity, profession, level)entity, data id, integer?-发送分配职业命令。
engine.network.send_give(entity, item, count)entity, data id, integer-发送给予物品命令。
engine.network.set_command_handler(fn)function-设置收到网络命令后的 Lua 回调；回调表包含 type、type_name、sequence 和命令字段。
engine.network.is_connected()-bool网络层是否已初始化。
engine.network.mode()-string返回当前网络模式名称。
engine.terrain.height_at(x, z, cfg)integer, integer, table?integer查询地形高度，可传配置表。
engine.terrain.register_biome(table)table-注册 biome，常在 on_world_init 使用。
engine.terrain.list_biomes()-table列出 biome ID。
engine.terrain.register_ore(table)table-注册矿物分布：block、noise_scale、threshold、min_y、max_y。
engine.terrain.select_biome(seed, cx, cz)integer, integer, integertable返回选中的 biome 描述。
engine.locale.set_locale(id)string-切换当前语言。
engine.locale.get_locale()-string当前语言 ID。
engine.locale.get(category, key)string, stringstring按分类和 key 获取翻译文本。
engine.locale.t(key)stringstring翻译完整 key。
engine.locale.list_locales()-table列出所有可用语言。
engine.locale.reload()--重新加载本地化资源。
engine.locale.load_locale(id, path)string, stringbool从文件加载语言包。
engine.equipment.register_slot(name)stringbool注册装备栏位（如 weapon、armor、held_item）。
engine.equipment.equip(entity, slot, item_hash, count)entity, string, hashed id, integerbool将物品装备到指定栏位。
engine.equipment.unequip(entity, slot)entity, stringbool从栏位卸下物品。
engine.equipment.get_equipment(entity)entity idtable返回所有栏位及装备信息。
engine.equipment.get_slot(entity, slot)entity, stringtable返回指定栏位的装备信息。
engine.equipment.has_slot(name)stringbool检查栏位是否已注册。
engine.world.remove_block(x, y, z)integer, integer, integer-移除指定坐标的方块。
engine.world.place_block(x, y, z, block_id)integer, integer, integer, string-在指定坐标放置方块。
engine.world.get_block(x, y, z)integer, integer, integertable查询方块，返回 { exists, id }。
engine.util.data_id_hash(id)data idhashed id计算 data ID 的 FNV-1a 哈希值，用于 inventory/equipment 交互。
