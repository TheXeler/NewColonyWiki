Wiki/要闻注册

玩家事件与待办

按《事件系统》替换旧要闻界面，继续使用 data/focuses/ 及既有实例、历史、存档和同步能力。内部 Lua 事件总线仍使用 data/events，不是玩家事件内容目录。

当前状态

设计文档规定了交互和配表字段，没有提供具体事件内容表。CoreMod 不自动创建首位殖民者、宣战、奖励等实际事件。第三方 Mod 使用相同注册契约提供内容。

入口与处理流程

底部“事件”入口显示叹号和全部未处理数量。常规事件在右侧显示彩色提醒，点击进入右侧待办总览；单击事件打开居中详情和选项。暂时忽略只关闭展示，不调用服务端移除接口，待办数不变。忽略状态属于当前客户端会话，重连、换世界或 Mod 重载后未处理事件可以重新提醒。

重大事件自动打开详情并阻止世界输入和模拟推进，不能用 Escape 或忽略跳过。多个重大事件按较小 priority、较早 tick、UUID 排队，逐个处理。普通事件采用相同稳定顺序。选项禁用时展示原因，提交后等待权威结果和待办更新；拒绝时保留事件。没有选项的通知通过“确认”完成。

其余字段沿用 id、title、body、severity、icon、conditions、one_shot、cooldown_ticks、choices。choices 是数组，每项有唯一 id、label、description、action、enabled、reason，支持文档中的五组选项，并通过换行、滚动适应更多内容。触发条件与效果继续由 Lua 注册扩展，不根据内置事件 ID 增加原生分支。每个已发布实例保留当时的展示字段和原选项，定义重载不改写它们。

效果与完成

即时事件由服务端 Lua 调用 engine.focuses.trigger(id) 发布已加载定义，返回 {ok=true,focus_uuid=...} 或 {ok=false,error=...}。缺少定义、逻辑侧无权、禁用、一次性已触发或仍在冷却时拒绝；不允许客户端自造实例或效果证明。显式 conditions: [] 表示仅由 Lua 发布，不自动轮询触发；有条件的定义保留原自动触发方式，也可以被 Lua 主动发布。冷却在 tick 0 首次触发后同样生效。暂停期间仍可发布事件并提交选择。

engine.focus.register_choice_action 的回调返回 true 表示接受，false 表示拒绝并保留待办；旧回调的无返回值 / nil 继续视为接受，其他类型是错误。空 action 是合法无效果选项。效果必须使用已有权威原子操作，并在拒绝前保留资产；任意 Lua 回调报错不会自动回滚此前的世界写入。

客户端提交原事件 UUID 和 choice_id，服务端重查实际实例和选项 enabled，阻止同实例回调重入。效果接受后使用不分配内存的步骤完成原实例，再发送通知；通知失败记录错误，不把已接受选择报告为可重做。engine.focuses.dismiss 只允许确认无选项通知，不能绕过带选项事件的效果。“暂时忽略”始终是客户端操作。

暂停与联机范围

服务端 Lua 的玩家命令入口重查重大待办顺序，不能通过过期界面请求越过当前重大事件去完成其他待办。受信任的 Mod 服务端策略仍可使用底层实例接口处理事件；界面快照本身不提供世界写入权限。

沿用既有世界共享范围：所有连接玩家查看同一批待办，具有 play 命令权限的玩家可以处理，首个服务端接受的处理完成原实例。尚无殖民地或阵营私有收件箱。重大事件暂停整个服务器模拟；网络、界面和命令继续服务。

暂停屏障从实际活跃重大事件派生，与玩家手动暂停和速度分开。最后一个重大事件完成才解除屏障，保留手动暂停和原速度；读档与网络候选发布后重建屏障。当前 Tick 在既有安全边界结束后停止后续 Tick，不中断执行到一半的事务。客户端详情提示暂停，权威停止发生在服务器。

原生界面

assets/ui/rml/events.rml 与 events.rcss 由原生面板注册表加载；ui.events_panel 提供 events_state，类型化 events 数据视图绑定列表、选项、文本和禁用状态。core:events.action 管理客户端展示，core:events.act 请求服务端处理。常规 Escape 先关详情再关总览，重大详情不可跳过。列表、正文和选项滚动，窗口按视口比例布局，窄窗口选项换行。没有浏览器运行时或源目录加载旁路。

第三方记录契约

第三方记录仍需显式声明稳定 ID、显示文本、触发条件、一次性状态和选择项。引擎只执行已注册内容，不补概率、周期、奖励或关系变化。

要闻历史与存档摘要

focuses 文档新增 format_version: 2，活跃项完整保存 summary、event_type、color、severity、icon、priority 和 choices（包括 action / enabled / reason）。磁盘与网络共用候选恢复，读档保留原选项。无版本或版本 1 沿旧定义补齐选项和类型，概括使用历史正文；旧格式没有保存的信息无法还原。无效快照或其他版本拒绝恢复。网络协议版本保持 1。

每次已提交的要闻触发均以原实例编号、UUID、定义 ID、Tick、标题和正文进入原生要闻历史。选择或关闭仅移除待处理项，历史保留；重载内容保留已记录文本，新世界／卸载清空运行态。历史通过既有 focuses 磁盘和网络文档保存／恢复，不重发触发通知；恢复校验完整身份和活跃项关联。历史记录可保留已移除定义，待处理选择仍要求定义存在。

存档浏览器“最近要闻”投影最近 5 条历史，按 Tick、实例编号倒序排列；展示记录的标题、正文和游戏日期，保留模组命名空间和本地化引用。没有要闻时显示空状态，经营结算日志和内部事件不会进入此列表。这里只提供记录能力，不新增触发策略、概率或私有要闻内容。
