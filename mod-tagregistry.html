标签数据

标签用于让配方、过滤和资格表达式引用一组稳定数据 ID。标签是数据分组，不产生物品、配方或掉落内容。

格式

{
  "tag": "example:materials",
  "values": ["example:item_a", "example:item_b"],
  "replace": false
}

values 中的 ID 必须存在于对应注册表；replace 决定覆盖还是合并已有标签。CoreMod 当前不提供具体物品标签内容，避免重新引入已删除的金属、木板或配方条目。

边界

  • 标签不能替代统一物品实例、预留或产出表。
  • 方块采集结果只能来自 output_table，不能由标签推导。
  • 空标签内容不会生成默认成员。
