战斗规则

2026-07-20 V2 版本只实现近战小队的基础战斗，不接入远程、法术、压制和区域法力规则。施法栏目前只保留 HUD 布局占位。

小队交战

小队以队长实体为锚点，虚拟士兵人数存在 Squad.member_count。战斗系统会生成 SquadSoldierVisual 临时实体来显示士兵方阵，保存世界时会跳过这些显示实体。两个敌对近战小队的任一队长/士兵模型接触时进入战斗态；敌方死亡、双方脱离接触或不再敌对时回到和平态。

敌对关系优先读取 NpcFactionSystem 的双边关系，关系低于阈值时敌对。文明 ID 到 NPC 阵营实例 ID 的桥接未完成时，当前接入点可选择不同阵营即敌对的严格 fallback。

碰撞与移动

战斗态小队被视为阻挡单位；和平态小队可轻微穿行并降低移动速度。导航系统可以通过 CombatSystem::is_blocking() 和 CombatSystem::move_modifier() 接入。战斗模式指令由 CombatSystem 直接推动队长朝移动目标或攻击目标靠近，移动时会避免穿过其他小队的接触范围。

命中、伤害与冷却

规则公式
队长命中率hit - dodge + 35，结果按百分比夹到 5 到 95。
队长伤害base_attack + equipment_bonus；装备加成等待物品系统接入。
士兵伤害每名士兵固定 1 点，不做命中判定。
攻击冷却使用隐藏值 Squad.attack_cooldown，V2 测试小队默认 5 秒一次。
移动速度V2 测试小队基础战斗移动速度为 1；战斗态再由移动接入点降低。

命中随机使用确定性随机种子，由 tick、攻击者、目标和本 tick 攻击序号混合得到，不依赖实体遍历顺序。

多队战斗

第三支小队加入战斗时仍使用同一套队长命中和士兵固定伤害逻辑。V2 不产生夹击压制，也不读取武器克制或压制规则 JSON。

T5 查询语义

C++ 查询返回用途
CombatSystem::list_squads(world)战斗 HUD 小队列表：生命、人数、目标、战斗态、阵营和兼容用武器粗分类。
CombatSystem::is_in_combat(world, leader)小队是否处于战斗态。
CombatSystem::is_commandable(world, leader)普通移动指令是否可用；战斗态应走战斗指令。

测试命令

开发者控制台命令 combat_test_arena [squads x y z half_size] [sx sy sz player|enemy ...] 会创建封闭平整区域、把摄像机移动到中心，并放置 V2 测试小队。未提供显式坐标时会在中心两侧自动排布；提供每队 x y z side 时按指定位置和玩家/敌方归属生成，玩家方会自动选中。测试小队属性为人数 20/20、生命 100、攻击 10、攻击冷却 5、命中 20%、闪避 20%、移动速度 1、射程 0。

战斗 HUD 与输入

CoreMod/assets/ui/rml/battle_hud.rml 是独立 RML 文档，由 CoreMod/scripts/ui/combat_hud.lua 通过 engine.ui.rml.register_panel 注册。底部栏战斗入口和 RML 内关闭按钮都发 core:combat.toggle_hud；模块切换面板可见性、维护 UI 侧 battle_mode，并回写 core:combat_entry 的 active 状态。

战斗快捷键：battle_select_squad_1..10 绑定数字键 1-0，按花名册顺序直接选中第 1-10 个小队（战斗模式专属占用，速度键 1-4 在战斗模式下让位；Ctrl+数字 仍用于保存 control group）；R/P/D/Z/S/Y/A/U 对应全选、编队、原地防御、移动、停止、镜头跟随、攻击、选近战。上一/下一小队循环（Q/E）默认未绑定，可在设置中自行绑定。A/S/D/E 与相机按键重叠；战斗模式下 InputManager 压制 A/S/D/E（以及 SetSpeed1..4）对应的动作，右键长按用于移动目标，横向拖动累计为方阵宽度变化，鼠标位置作为朝向来源。右键相机拖动在战斗模式下被压制，新增中键 CameraOrbit 绑定作为镜头拖动 fallback。进入战斗模式时底部游戏内菜单暂时隐藏（hud.rml 的 #bottom-bar-slot 以 battle_hud_view.visible 为条件），退出后恢复。

SelectionManager 保留旧单选接口，并新增多选集合、框选矩形、Shift 追加、十个 control group、上一/下一小队循环、全选小队、近战/远程过滤接入点，以及双击小队请求镜头跳转的一次性信号。世界点击队长或士兵显示实体都会映射回队长；世界双击和 HUD 行双击都会把镜头移动到小队队长。HUD 行点击会在命令分发时读取当前 Shift 状态来追加或取消选择。
