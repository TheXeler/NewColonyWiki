Wiki/着色器格式

着色器格式

着色器源码放在 assets/shaders/ 下，使用 GLSL 编写。引擎启动时通过 glslangValidator 自动编译为 Vulkan SPIR-V 字节码。

支持的格式

类型扩展名说明
顶点着色器.vertGLSL 4.50 顶点着色器源码。
片段着色器.fragGLSL 4.50 片段着色器源码。
计算着色器.compGLSL 4.50 计算着色器源码。
几何着色器.geomGLSL 4.50 几何着色器源码。
曲面控制着色器.tesc细分控制着色器。
曲面求值着色器.tese细分求值着色器。

编译流程

引擎在启动时使用 glslangValidator 将 GLSL 源码编译为 Vulkan SPIR-V 字节码（.spv）。编译后的文件缓存在构建目录中，源码未修改时跳过编译。

assets/shaders/block.vert     -- 源码（MOD 提供）
    ↓ glslangValidator（启动时自动执行）
build/bin/block.vert.spv      -- 编译产物（自动生成）
着色器文件必须使用 .vert、.frag 等标准扩展名。引擎按扩展名识别着色器类型。不支持预编译的 .spv 文件——源码必须在启动时可被 glslangValidator 编译。

着色器版本

使用 #version 450 或更高版本。渲染后端为 Vulkan，不支持 #version 330 等 OpenGL 版本。

引擎绑定点

绑定类型说明
binding = 0UBO视图/投影矩阵（view, projection）
binding = 1sampler2D纹理图集采样器

示例：方块顶点着色器

#version 450

layout(binding = 0) uniform UBO {
    mat4 view;
    mat4 projection;
} ubo;

layout(location = 0) in vec3 inPosition;
layout(location = 1) in vec2 inTexCoord;

layout(location = 0) out vec2 fragTexCoord;

void main() {
    gl_Position = ubo.projection * ubo.view * vec4(inPosition, 1.0);
    fragTexCoord = inTexCoord;
}

示例：方块片段着色器

#version 450

layout(binding = 1) uniform sampler2D texSampler;

layout(location = 0) in vec2 fragTexCoord;
layout(location = 0) out vec4 outColor;

void main() {
    outColor = texture(texSampler, fragTexCoord);
}
