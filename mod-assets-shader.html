Wiki/着色器格式

着色器格式

着色器源码放在 assets/shaders/ 下，使用 GLSL 编写。启动预处理阶段会通过打包的 glslangValidator 编译为 Vulkan SPIR-V 字节码。

支持的格式

类型扩展名说明
顶点着色器.vertGLSL 4.50 顶点着色器源码。
片段着色器.fragGLSL 4.50 片段着色器源码。
计算着色器.comp会被预处理编译；当前主渲染管线没有通用 MOD 计算管线接入。
几何着色器.geom会被预处理编译；当前内置 Vulkan 管线不加载几何阶段。
曲面控制着色器.tesc会被预处理编译；当前内置 Vulkan 管线不加载细分阶段。
曲面求值着色器.tese会被预处理编译；当前内置 Vulkan 管线不加载细分阶段。

编译流程

引擎在启动时使用运行目录下的 tools/glslang/glslangValidator 将 GLSL 源码编译为 Vulkan SPIR-V 字节码（.spv）。编译后的文件缓存在 generate/<mod_id>/shaders/ 中，源码未修改时跳过编译。

assets/shaders/block.vert     -- 源码（MOD 提供）
    ↓ glslangValidator（启动时自动执行）
generate/core/shaders/block.vert.spv
                              -- 编译产物（自动生成）
着色器文件必须使用 .vert、.frag、.comp、.geom、.tesc 或 .tese 扩展名。引擎按扩展名识别源码类型。不支持把预编译 .spv 当作 MOD 源文件提交。

着色器版本

使用 #version 450 或更高版本。渲染后端为 Vulkan，不支持 #version 330 等 OpenGL 版本。

方块管线绑定点

绑定类型说明
binding = 0UBO主 UniformBufferObject；具体字段需与内置 shader 和 C++ UBO 保持一致。
binding = 1sampler2D方块/实体运行时纹理图集采样器。

示例：方块顶点着色器

#version 450

layout(binding = 0) uniform UBO {
    mat4 view;
    mat4 projection;
} ubo;

layout(location = 0) in vec3 inPosition;
layout(location = 1) in vec2 inTexCoord;

layout(location = 0) out vec2 fragTexCoord;

void main() {
    gl_Position = ubo.projection * ubo.view * vec4(inPosition, 1.0);
    fragTexCoord = inTexCoord;
}

示例：方块片段着色器

#version 450

layout(binding = 1) uniform sampler2D texSampler;

layout(location = 0) in vec2 fragTexCoord;
layout(location = 0) out vec4 outColor;

void main() {
    outColor = texture(texSampler, fragTexCoord);
}

内置着色器

CoreMod 提供多组内置着色器。当前主渲染和后处理代码按固定文件名加载这些 .spv：

着色器文件用途
方块渲染block.vert + block.frag体素方块的标准渲染管线。
天空盒skybox.vert + skybox.frag天空盒渲染。不使用深度测试和深度写入。
GPU 调试几何debug.vert + debug.frag绘制带深度测试的调试线框和半透明调试面。
SSAOssao.vert + ssao.frag屏幕空间环境光遮蔽。
SSAO 模糊ssao_blur.vert + ssao_blur.fragAO 结果模糊。
体积光遮罩volumetric_light_mask.vert + volumetric_light_mask.frag生成体积光遮罩。
体积光模糊volumetric_light_blur.vert + volumetric_light_blur.frag体积光模糊。
合成composite.vert + composite.frag合成场景、AO 和体积光。
区块剔除 Computechunk_cull.comp区块 GPU 剔除管线入口，供后续 compute frustum/occlusion culling 使用。
目前没有公开的“新增自定义渲染管线”MOD API。MOD 可以提供会被预处理的 shader 源码，但只有被 C++ 渲染代码按固定名称引用的 shader 会实际进入管线。
