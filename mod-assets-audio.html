Wiki/音乐格式

音乐和音效格式

音频文件放在 assets/audio/ 下，通过 sound bank JSON 注册。引擎使用 miniaudio 后端，支持 WAV、MP3、FLAC 和 OGG 四种格式。

支持的格式

格式扩展名特点适用场景
WAV.wav无压缩，文件较大，加载快短音效（挖掘、放置、点击）
MP3.mp3有损压缩，文件小背景音乐、较长音效
FLAC.flac无损压缩，音质最好，文件较大高品质音乐
Vorbis.ogg开源有损压缩，文件小且音质好背景音乐、环境音
音频后端使用 miniaudio 库，自动检测文件格式。只要文件路径能被 sound bank 解析，后端会按内容解码。

音频分类

分类category 值说明建议格式streaming 建议
音乐music背景音乐。受音乐音量滑块控制。OGG / MP3true
音效effect短促的游戏音效。受音效音量滑块控制。WAVfalse
环境ambient环境氛围声。可能循环播放。受环境音量滑块控制。OGG / WAV视长度而定

音频注册

sound bank JSON 使用 sounds 数组注册音频文件：

{
    "sounds": [
        {
            "id": "my_mod:title_theme",
            "file": "assets/audio/music/title_theme.ogg",
            "category": "music",
            "streaming": true,
            "loop": true,
            "volume": 0.8
        },
        {
            "id": "my_mod:pickaxe_hit",
            "file": "assets/audio/effects/pickaxe_hit.wav",
            "category": "effect",
            "streaming": false,
            "volume": 0.6
        },
        {
            "id": "my_mod:wind",
            "file": "assets/audio/ambient/wind.ogg",
            "category": "ambient",
            "streaming": true,
            "loop": true,
            "volume": 0.4
        }
    ]
}

sounds.json 字段

字段类型必填默认值说明
idstring是—音频的唯一标识。后续通过此 ID 播放。
filestring是—音频文件的相对路径（相对于 MOD 根目录）。
categorystring否effect音频分类：music、effect、ambient。
streamingbool否false是否流式加载。长音频建议设为 true 以减少内存占用。
loopbool否false是否循环播放。
volumefloat否1.0默认音量（0.0~1.0）。与分类音量相乘得到最终音量。

当前加载边界

当前启动流程只会调用一次 AudioSystem::load_sound_bank，路径是运行目录下的 data/audio/sounds.json（CoreMod 被复制到运行目录后的核心 sound bank）。data/audio 不进入通用 ModLoader 注册表，也不会自动扫描每个 active MOD 的 data/audio/sounds.json。

这意味着内容型 MOD 可以参考本页格式准备音频资源，但“每个 MOD 自动加载自己的 sound bank”还不是当前稳定功能。要让自定义音频真正可播，需要后续接入音频加载流程或由引擎显式调用 load_sound_bank。

Lua 播放接口

-- 播放音效
local handle = engine.audio.play("sfx_button_click")

-- 指定音量和循环
local music = engine.audio.play("bgm_main_menu", 0.7, true)

-- 3D 空间音频（音效从指定世界坐标发出）
engine.audio.play_3d("sfx_block_place", x, y, z, 0.8)

-- 停止单个播放实例或停止全部
engine.audio.stop(handle)
engine.audio.stop_all()

-- 音量控制
engine.audio.set_master_volume(0.8)
engine.audio.set_music_volume(0.65)
engine.audio.set_effects_volume(0.75)
engine.audio.set_ambient_volume(0.55)

格式选择建议

  • 短音效（< 3 秒）：使用 WAV。无解码开销，即用即播。
  • 背景音乐：使用 OGG。文件小，streaming 模式下内存占用低。
  • 环境循环音：使用 OGG 或 WAV。需要循环的音频确保首尾能平滑衔接。
  • 高品质需求：使用 FLAC。音质最好但文件最大，仅在必要时使用。
engine.audio.play 和 play_3d 只能播放已经注册到 SoundBank 的 ID。未知 ID 会记录警告并返回无效句柄 0。
