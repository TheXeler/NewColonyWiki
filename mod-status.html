当前能力状态

帮助 MOD 作者判断哪些能力可以稳定依赖，哪些还处在接入、实验或未完成阶段。列表基于当前代码库的实际加载路径、系统初始化和 CoreMod 数据目录核对。

可稳定依赖

以下能力已经接入主流程，MOD 可以按公开文档使用。

能力状态说明
MOD 发现与加载可用mod.json、依赖排序、load_before 通配符、严格清单校验、用户设置覆盖和 MOD 翻译合并均已接入。
数据注册可用ModLoader::load_mod_data 当前稳定加载 14 类 JSON：blocks、entities、recipes、professions、civilizations、focuses、factions、name_pools、actions、features、crops、buildings、biomes、zones。
数据诊断可用重复 MOD ID、重复数据 ID、无效字段、配方/职业/文明/作物/方块引用错误会报告明确来源。
Lua 生命周期可用入口脚本支持 on_load、on_world_init、on_tick、on_shutdown。
Lua 事件与定时器可用engine.events 支持订阅、发布和取消订阅；engine.timers 支持 after、every、cancel、clear。
Lua 随机数 API可用engine.random.seed/float/int/bool 使用 Xoshiro256** 确定性 RNG。
职业与配方可用职业等级、转职方块、前置职业、配方输入输出、职业要求、文明配方限制和解锁均已从注册表初始化。
文明可用文明定义、初始方块/职业、配方修正规则和 TechTree 入口已接入；当前 CoreMod 有 2 个文明。
焦点系统可用玩家可见焦点事件支持 tick、实体数量、殖民者需求、Lua 条件和选项。
NPC 阵营与名称池可用factions、name_pools、模板命名、阵营实例、关系值和外交动作已接入。
本地化可用核心语言文件、MOD 翻译合并、UI 文本查询、Lua locale API 和运行时热重载已接入。
ECS 基础可用Archetype 存储、组件查询、实体 ID 代际和 26 种标准组件可用。
网络同步可用TCP Host/Client、快照广播、客户端命令、客户端预测、延迟补偿、重连恢复、增量快照和 MOD 数据交换已实现。
控制台调试可用当前注册 75 个命令，覆盖 MOD、数据、配方、实体、背包、阵营、网络、存档、Lua 热重载、配置诊断和归档对比。

部分可用

这些系统已有核心代码或运行入口，但不应被 MOD 当作完全稳定承诺。

能力状态已实现未完成或风险
AI 行为 部分 需求驱动、WorkPool、JobRegistry、ActionRegistry、A*、NavMesh/NavAgent、行为树、Blackboard、默认殖民者树和战斗树。 挖矿、搬运入库、建造材料预留、施工推进和农业产出已接入 WorkPool/Lua 事件闭环；巡逻、社交和紧急行为仍需继续完善。
作物与农业 部分 data/crops 已由加载器校验和注册；CoreMod 有 8 个作物定义；Lua farming 系统会读取 crop registry 生成耕地、播种、成熟和收获任务。 多作物产出已进入库存账本；温度、湿度和 UI 反馈仍待继续数据驱动。
区域系统 部分 ZoneSystem、Lua engine.zone、矩形/3D 区域创建、查询、删除和 CoreMod 区域脚本已存在；data/zones 已由 ModLoader 自动加载。 库存区已作为 CoreMod 账本物流入口使用；居住区高层行为仍较薄。
建筑系统 可用 data/buildings 已作为标准 mod_data 加载、校验并由 BuildingSystem 读取；建筑材料和文明 starting_buildings 会做注册表交叉校验。 建造订单会等待库存材料，预留成功后发布施工任务并推进 BuildingSystem；多阶段施工表现仍是 Alpha 级实现。
音频 部分 miniaudio 后端、SoundBank、CoreMod data/audio/sounds.json、Lua engine.audio 播放/停止/音量 API 已存在。 音频不是通用 data/ 注册类型；当前只从 CoreMod 路径加载 sound bank，MOD 音频发布流程仍需完善。
UI 系统 部分 ImGui 控制台、主菜单、多人菜单、小地图、Lua UI、底栏、窗口、浮动提示、城镇信息、区域指定、建造菜单和 CSS 主题基础。 Lua UI 渲染层和通用控件契约仍在完善，不建议 MOD 依赖内部细节。
存档 部分 v2 保存/加载框架、存档列表、原子写入、实体、阵营、Job、焦点状态和 MOD 依赖追踪。 跨版本向后兼容迁移、MOD 依赖自动解析策略和自定义组件序列化还未完成。
渲染与方块模型 实验 Vulkan 管线、Chunk 网格、纹理图集、BlockTextureRegistry 和多元素方块模型解析已实现。 渲染后端和复杂模型兼容性仍属于实验层，不作为 MOD API 稳定承诺。
体素地形与生物群系 部分 data/biomes 已作为标准 mod_data 加载、校验并注册到 TerrainGenerator；支持权重、地表/次地表方块、树木参数和洞穴/河流开关。 世界生成整体仍属实验层，复杂装饰和脚本扩展契约还在收敛。

给 MOD 作者的建议

当前最适合开发内容型 MOD：方块、实体原型、配方、职业、文明、焦点、NPC 阵营、名称池、动作、地物、作物、建筑、生物群系、本地化和少量 Lua 辅助逻辑。音频仍未作为通用 MOD 数据类型接入；AI 高级行为、UI 扩展、存档迁移和 MOD 打包发布也不建议作为强依赖。

AI Dispatch Notes

WorkPool dispatch keeps the existing worker priority calculation and now uses category/type indexes, same-type preference, utility scoring, and online HTN-style navigation/execute decomposition.
