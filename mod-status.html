当前能力状态

帮助 MOD 作者判断哪些能力可以稳定依赖，哪些还处在接入、实验或未完成阶段。列表基于当前代码库的实际加载路径、系统初始化和 CoreMod 数据目录核对。

可稳定依赖

以下能力已经接入主流程，MOD 可以按公开文档使用。

能力状态说明
MOD 发现与加载可用mod.json、依赖与加载顺序（dependencies/load_after/load_before，支持 load_before: ["*"]）、side、conflicts、settings、用户设置覆盖和 MOD 翻译合并均已接入。脚本沙箱不提供通用文件系统 IO 权限。
数据注册可用ModLoader::load_mod_data 稳定加载基础内容、经营规则、生态、动态天气、视野和难度等多类 JSON；professions 是 jobs 别名。
数据诊断可用重复 MOD ID、重复数据 ID、无效字段、配方/职业/文明/作物/方块引用错误会报告明确来源。
Lua 生命周期可用入口脚本支持 on_load、on_world_init、on_tick、on_shutdown。
Lua 事件与定时器可用engine.events 支持订阅、发布和取消订阅；engine.timers 支持 after、every、cancel、clear。
Lua 随机数 API可用engine.random.seed/float/int/bool 使用 Xoshiro256** 确定性 RNG。
职业与配方可用职业 1-5 级、装备实例许可、前置职业、配方输入、职业要求、文明配方限制和解锁均已从注册表初始化。公开直通制作已禁用，CoreMod 制作统一走带资源预留的生产订单；固定制作结果由产出表决定。
文明接口文明注册、运行态和存档接口保留；NCDOCS 没有文明专项内容，CoreMod 当前定义为空，不生成初始方块、职业或配方修正。
焦点系统接口焦点 schema、运行态和存档接口保留；CoreMod 内容为空，不生成未在 NCDOCS 定义的随机事件、选项或效果。
派系、城邦与外交接口factions、name_pools、faction_spawn_rules、双边关系和空的提案/谈判 schema 可用；世界地图与外交页只显示状态摘要。专项文档未建立前不生成城邦资源/发展、默认提案、贸易积分或 AI 周期外交。
战斗接口职业战斗属性、伤病/倒地/死亡和小队身份/成员状态摘要保留；专项文档未建立前不推进小队移动、接敌、命中、伤害、冷却、压制、阵型或区域法力，所有战斗命令无副作用拒绝，HUD 只显示接口未定。
本地化可用本体语言文件、CoreMod/MOD 翻译合并、UI 文本查询、Lua locale API 和运行时热重载已接入。详见本地化与翻译。
ECS 基础可用Archetype 存储、组件查询、实体 ID 代际和标准组件集可用；组件集合会随殖民者生存、选择和渲染状态继续演进，不以旧固定数量作为兼容承诺。
网络同步部分TCP Host/Client、Host 权威 UiCommand、命令结果、重连恢复、增量快照和 MOD 数据交换已实现；活体网络往返仍待显式验证。
控制台调试可用当前注册约 80 个命令，覆盖 MOD、数据、配方、实体、背包、阵营、网络、存档、Lua 热重载、配置诊断和归档对比。

部分可用

这些系统已有核心代码或运行入口，但不应被 MOD 当作完全稳定承诺。

能力状态已实现未完成或风险
AI 行为 部分 WorkPool、WorkRegistry、A*、NavMesh/NavAgent、行为树、个人队列和来源结算接口。导航推进层只向实体下发局部 MovementTarget；实体运动层生成 MovementIntent 并据局部目标更新 Rotation；物理层消费意图后使用 PhysicsCollider 独立处理速度、体素/实体碰撞和权威位置。 搬运、施工、生产、饮食和治疗已接入事务闭环；未有专项规则的农业、巡逻、社交和战斗行为不生成默认玩法。
作物与农业 部分 data/crops schema 与加载接口保留；CoreMod 内容为空。种植专项循环未定义时不生成作物、生长阶段、成熟或收获规则。 当前只保留接口；不会声称存在作物产出、温湿度或收获循环。
区域系统 部分 ZoneSystem、Lua engine.zone、矩形/3D 区域创建、查询、删除和版本化存档已存在；CoreMod 只注册露天仓储区和种植区。 露天仓储区已接入统一物品系统；种植专项循环未定义，旧居住、收获和采掘持续区域不存在。
建筑系统 部分 data/buildings schema、BuildingSystem、施工事务、工作点、存储点、治疗点、耐久、维修和版本化实例存档已接入。 NCDOCS 未给出具体建筑形状、材料或工期，CoreMod 内容为空；加入完整定义后才会开放对应建造入口。
音频 部分 miniaudio 后端、SoundBank、data/audio 注册表接入、Lua engine.audio 播放/停止/音量 API 已存在。 CoreMod 仅含占位音效条目，实际音频资源尚未附带；3D 空间化和分组混音仍属实验层。
UI 系统 部分 玩家可见 UI 统一走游戏内 RmlUI：主菜单、HUD、暂停/设置、开发者控制台、小地图和全局提示由静态 RML/RCSS 文档驱动；经营类游戏内菜单通过 Lua on_load 注册到底栏/窗口兼容层。旧即时模式/Lua 可见渲染层已移除。 Lua UI 兼容 API 已接入 RmlUI-backed 可见层，可显示底栏扩展、窗口/table/tabs_table、动态 RML 面板和浮动提示；MainMenuState 仍承载设置、暂停和世界创建状态。旧 CSS 主题后端不再应用样式，主题扫描只为旧配置兼容保留。
存档 部分 保存/加载框架、存档列表、原子写入、世界配置、天气、实体、文明研究、殖民者纪念记录、阵营、Job、工作资源预留、焦点状态和 MOD 差异诊断。详见存档系统状态。 完整活体往返、已删除/重命名内容的迁移规则、MOD 自定义组件序列化仍需完善；无限高度已迁移区块列、存档、网络、细分网格、导航、光源传播和 GPU/CPU 流体分片，自然地形生成及开发者 GPU 探针保留有限工作带；多体素部件已有稳定实例、明确体素集合、owner、建筑 parts 与版本化 Host 运行态，具体树形和门形仍等待专项文档定义。
渲染与方块模型 实验 Vulkan 管线、Chunk 网格、纹理图集、BlockTextureRegistry 和多元素方块模型解析已实现。 渲染后端和复杂模型兼容性仍属于实验层，不作为 MOD API 稳定承诺。
体素地形与群系 部分 data/biomes 和 data/terrain 作为标准 mod_data 加载、校验并注册到 TerrainGenerator；支持权重、地表/次地表方块、地图颜色和默认地形方块。旧 data/ores 已移除，矿物由矿井规则提供。 世界生成整体仍属实验层，复杂装饰和脚本扩展契约还在收敛。
