地形配置注册

地形配置放在 data/terrain/ 下，用 JSON 提供默认地形方块和部分全局地形参数。它与群系注册配合使用：群系决定地表/次地表，地形配置提供基础方块、水方块和导航流体深度等全局选项。矿物由矿井规则按区块提供，不作为普通地下矿物体素生成。

JSON 格式

{
    "id": "core:default",
    "base_block": "core:stone",
    "water_block": "core:water",
    "max_navigable_fluid_depth": 1
}

字段说明

字段类型必填说明
idstring是唯一标识。当前 chunk 地形配置优先查找 core:default；如果没有这个 ID，则使用注册表中的第一个 terrain 条目。
base_blockstring是基础实心方块 ID，必须引用已注册方块。世界生成在没有群系覆盖时使用它作为默认地下方块。
water_blockstring否水体方块 ID，必须引用已注册方块。省略时使用运行时默认水方块。
max_navigable_fluid_depthint否寻路可通过的最大流体深度，必须是非负整数。省略时为 0；0 表示不可涉水，1 表示可以穿过一格深的浅水。

读取顺序

  • 引擎会先建立默认 TerrainConfig，其中海平面来自创建世界或存档中的世界设置。
  • 随后从 data/terrain/ 注册表中选择 core:default；如果没有该 ID，则使用第一个 terrain 条目。
  • 选中的 JSON 覆盖 base_block、water_block 和 max_navigable_fluid_depth。
  • 群系仍然负责每列的 surface_block、subsurface_block、气候匹配和高度轮廓；terrain 配置不是群系列表。
当前世界生成只填充连续的地表和地下实心层，不执行地下洞穴雕刻；terrain 与 biome 数据均不提供洞穴开关或洞穴参数。
CoreMod 当前的 data/terrain/default.json 将 max_navigable_fluid_depth 设为 1，因此殖民者可以穿过一格深的浅水。没有写出的字段会使用引擎默认值。

和其他注册表的关系

注册表职责
群系注册决定某个气候位置使用哪种表层方块、次表层方块、植被概率和高度修正。
地物注册在地表装饰阶段放置树木、石堆等地物。
方块注册提供 base_block、water_block、群系方块和矿物方块引用的实体数据。

文件放置规则

  • 放在 data/terrain/ 下，支持子目录。
  • 当前运行时只选用一个 terrain 配置。多个 MOD 同时提供 terrain 条目时，优先匹配 core:default，否则取注册表中第一个条目。
  • base_block 和 water_block 会在跨引用校验阶段确认存在；引用不存在会导致 MOD 加载失败。

验证命令

在控制台（按物理 Grave/反引号键）中确认地形配置注册：

list_data terrain               -- 列出所有已注册的地形配置
data core:default               -- 查看默认地形配置 JSON
data type:terrain               -- 查看 terrain 类型下的注册数据
