MOD 开发手册

将 MOD 从最小示例扩展成可维护内容包的阅读路线。

本页是流程导航。需要具体格式时，请进入对应的参考页面。

推荐流程

如果你是第一次做 MOD，按下面顺序走一遍：

  1. 先完成 快速开始，确认 MOD 能加载。
  2. 阅读 MOD 是怎样加载的，理解数据注册和脚本执行的先后关系。
  3. 阅读 清单文件，整理依赖、版本和配置项。
  4. 用 方块注册 添加新方块和物品。
  5. 需要规则逻辑时，再接入 Lua API。
  6. 最后用 调试控制台 检查数据和脚本。

写作原则

  • 能用 JSON 表达的内容优先放在 data/。
  • Lua 只处理数据难以表达的规则、条件和选项行为。
  • ID 使用 <mod_id>:<name> 格式，避免和其他 MOD 冲突。
  • 公共文档没有列出的内部字段，不要当作兼容依赖。

从示例复制

最省事的做法：参考 CoreMod/ 的完整目录结构，按相同模式组织你的 MOD 数据和脚本。CoreMod 提供了方块、职业、文明、配方、焦点和完整事件的标准示例。
