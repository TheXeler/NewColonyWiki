状态自动演进与别名

日常只需维护当前数据声明：新增字段写类型和默认值，改名加别名，改变含义时才提供转换函数。不需要为普通字段变化手动递增版本号。该能力属于现有 @State 受管状态机制，应用于世界存档、本地设置和候选热重载。源码已接线；尚未执行检查、构建或测试。

最常见的用法

@State 仍为 Lua 文件顶部的一行 JSON 注释。以下每个声明均须保留为一整行：

-- @State workshop {"type":"object","storage":"world","default":{},"fields":{"progress":{"type":"number","default":0,"aliases":["work_progress"]},"enabled":{"type":"boolean","default":true}}}
local Workshop = {}
function Workshop.advance(amount)
    state.workshop.progress = state.workshop.progress + amount
end
return Workshop

旧值 work_progress 自动读为 progress；缺少 enabled 时填入 true。修改默认值只影响缺失值和新状态，已有值保持。false、0 和空字符串都是已有值。新旧字段同时存在时，值相同可合并，不同则报告具体字段冲突并拒绝这次状态恢复。

固定记录、动态 Map 与缓存

声明行为
type: object, fields: {...}固定记录。按声明递归补默认值、应用别名；未声明字段不进入规范结果，之后保存省略它们。原存档文件不在加载时改写。
type: object, values: {...}以任意字符串为键的动态 Map；键原样保留，每个值按 values 递归处理。适合实体 UUID、任务 UUID、命名条目。
type: object，省略 fields/values开放 JSON 对象，原样保留动态内容。现有仅声明根类型的玩法状态不会因此递归删除未知字段。
additional_fields: true固定字段仍正常处理，额外字段作为开放扩展区保留；指定 values 时额外字段按 values 校验。
type: array, items: {...}保持连续数组顺序并递归处理每项；拒绝稀疏数组。将 transient 标记放在整个数组字段上，不放在 items 上。
transient: true不保存该字段；恢复时忽略旧缓存并按默认值初始化。所属模块仍负责从权威数据重建索引。
无默认值且非 required允许缺失，不制造值。读取结果可以为 nil。
required: true 且无默认值缺失时报告错误，要求作者给出明确转换规则。
 
-- @State residents {"type":"object","storage":"world","default":{},"values":{"type":"object","fields":{"name":{"type":"string","required":true},"level":{"type":"integer","default":1}}}}
-- @State index {"type":"object","storage":"world","default":{},"transient":true}

支持 boolean、number、integer、string、uuid、object 和 array。integer 要求 Lua 可精确表示的安全整数，可用 minimum/maximum 声明边界；number 必须有限。整数值可被 number 接受，但不会把字符串猜成数字、把小数截为整数，或在类型不匹配时用默认值覆盖。

内容 ID 改名

在当前内容定义上列出它以前的名字。别名必须属于提供该定义的 Mod 命名空间，并限制在对应注册表内：

{"id":"example:iron_ingot","aliases":["example:iron_bar","example:old_iron"],"...":"该类型的其他必需字段"}

保留全部历史名字，它们直接指向当前定义，无需逐次追链。自身、重复、跨提供者命名空间以及与当前定义或其他别名冲突的声明会拒绝；注册顺序不能决定冲突结果。按类型列举只返回规范定义，不重复列出别名。覆盖定义时以新声明中的 aliases 为准；移除提供者也会移除别名。

engine.modding.resolve_id(type,id) 返回规范字符串 ID，不存在时返回空字符串。get_data_json 和 get_data_source 的查找也接受别名。物品字符串查询及地形存档的方块 ID 重映射使用同一规范定义。hash 工具保持纯计算；不要把未知内容字符串直接 hash 后当作已解析的定义引用。

受管状态中的内容引用加一个 registry 即可自动解析：

-- @State target {"type":"string","storage":"world","default":"example:iron_ingot","registry":"items"}

只有明确标为该注册表引用的值会转换，普通字符串和 UUID 不替换。其他原生子系统独立维护的类型化记录仍由其编解码器负责，不对整份存档执行字符串替换。本机制不改变现有引擎版本匹配规则，也不自动承诺所有历史原生存档均可加载。

模块文件改名

在新模块顶部增加一行 @StateModule，声明旧模块名；无命名空间时自动使用当前 Mod：

-- @StateModule {"aliases":["systems.old_workshop"]}
-- @State workshop {"type":"object","storage":"world","default":{}}

恢复时按新模块接收状态，之后保存新模块名。它只负责状态所属标识，不改变 Lua require、事件监听器或定时任务类型。新旧模块数据同时出现时拒绝恢复，避免合并不同权威数据。跨 Mod 模块别名、与已声明模块冲突的别名会拒绝。

只有语义变化才写转换器

例如把秒换成分钟，在字段声明中增加 convert：

-- @State duration {"type":"number","storage":"world","default":0,"convert":"state_converters.duration"}

scripts/state_converters/duration.lua 必须是本 Mod 的无状态模块，返回一个函数：

return function(old, context)
    -- 第一次接入的旧存档可以没有 old_schema。
    local previous = context.old_schema
    if previous == nil or previous.convert == nil then
        return old / 60
    end
    return old
end

context 提供 module_id、field_path、old_schema 和 current_schema；参数与返回值均为独立 JSON 数据。转换器在新的受限环境执行，没有 engine、state、require、文件、时钟、网络或随机数，也不能保留上次调用的闭包状态。只开放基本断言、类型和数值转换以及 math/string/table 的确定性工具。必须恰好返回一个值；异常、无效类型或不可序列化结果拒绝恢复。

转换发生在自动规范化之前，能够处理拆分字段或容器形状变化。缺失字段直接使用当前默认值，不调用转换。普通保存不运行转换器。已经接受且结构语义相同的转换不会在再次读档时重放；修改默认值、别名或数值限制不重放转换。如果同名字段结构不变但含义再次变化，可显式修改字符串 revision，并在转换器中根据旧声明区分原始数据和已经转换的数据。原生世界操作和跨模块业务变更仍应通过既有权威事务实现，不能借数据转换器绕过。

结构记录、失败和诊断

引擎自动在每个有持久字段的模块快照加入保留字段 __nc_schema：format、稳定结构标识 id 和完整 schema。作者无需维护普通结构版本。旧快照没有该记录时按当前声明处理；损坏或未来格式拒绝。标识用于诊断，不代替完整结构信息。不要把自定义字段命名为 __nc_schema。

恢复先构造所有模块候选，全部处理成功后再替换受管状态。失败保留原受管状态，原存档文件也不被改写。这个保证限于受管状态恢复批次；不表示整个原生世界加载已新增跨原生／Lua 的整体回滚。跨 world/local 存储范围的变化需要明确转移，不能仅改 storage 后静默丢弃原数据。

缺失或禁用模块的世界／本地状态按原标识保留，重新启用后仍可读取。世界脚本缺失的执行逻辑继续沿既有损失报告和确认流程处理；保存数据不等于允许缺失逻辑继续运行。热重载仍遵守其更严格的拒绝边界。

模块可用 engine.state.changes() 查看最近成功恢复的本模块摘要，返回脱离状态的 {action,path,storage,count} 行。记录补默认值、字段别名、引用解析、转换、缓存重置和字段省略；每个模块每种存储最多保留 128 个不同路径样本。失败不替换上次成功报告。该报告只是诊断，不是业务账本。

engine.state.read(field, path) 读取本模块已声明的字段。路径是由字符串键和正整数索引组成的连续数组，空数组读取整个字段。缺失键返回 nil。该调用在正常执行和只读准备阶段都只复制路径末端的数据，返回值与托管状态隔离。世界字段要求已有活动世界。

任务完成回执、待确认通知、奖励去重记录不因“时间很旧”自动删除。是否还能重试或被引用，仍由所属共享机制定义。本功能没有添加定时全世界清理器，也没有恢复招募来源的专项旧存档清理。
