MOD 调试控制台

控制台是你调试 MOD 最重要的工具。按 ~ 键打开。

如果控制台没反应，先看 Logs/latest.log。即使控制台不可见，日志通常还是会写进 Logs/ 目录。

常用命令

命令用途
mods查看已加载的 MOD 列表。
mod_settings [mod_id] [key]查看 MOD 的最终配置值。
list_data [type] [page] [size] [prefix=...] [mod=...] [sort=asc|desc]分页查看数据。type 支持 items、blocks、entities、recipes、professions、civilizations、focuses；不传 type 时会列出全部类型。
data <id> / data type:<type>查看单条数据的详情，或列出某类型全部数据。data type:factions 和 data type:name_pools 可查看阵营和名称池。
list_recipes [page] [size] [prefix=...] [sort=asc|desc]查看所有已注册的配方。
list_protos [page] [size] [prefix=...] [sort=asc|desc]查看所有实体原型。
spawn_proto <id>按原型 ID 生成一个实体。
give <entity> <item> <count>给指定实体发物品。
craft <entity> <recipe>让指定实体执行一次合成。
inventory <entity>查看实体的背包内容。
list_factions / list_name_pools查看已注册的 NPC 阵营定义和名称池。
spawn_faction <faction_def_id> [seed]生成一个 NPC 阵营实例。
list_faction_instances查看已经生成的 NPC 阵营实例。
faction_relation <instance_id> <delta>调整阵营关系值，结果会被限制在定义的最小/最大关系内。
gen_name <template> [seed]按名称模板生成调试名称。模板里可写 ${random_name}。
net_status查看网络角色、连接状态和同步计数。
net_host [port] / net_join host [port]启动主机或连接到主机。
net_disconnect断开网络连接。
mod_list / export_mod_list列出/导出 MOD 列表及校验码（调试网络 MOD 一致性）。
lua <code>直接执行一段 Lua 代码。
save [name] / load [name] / save_list保存、加载和列出存档。
list_entities [page] [size]分页查看当前世界所有实体。
list_civs查看文明系统状态。

标准检查流程

做好 MOD 后，按这个顺序跑一遍，基本能把注册问题都找出来：

  1. mods —— 确认 MOD 出现在加载列表中。
  2. list_data items prefix=copper_age: —— 检查物品是否注册。
  3. list_data professions prefix=copper_age: —— 检查职业是否注册。
  4. list_data civilizations prefix=copper_age: —— 检查文明是否注册。
  5. list_data focuses prefix=copper_age: —— 检查 Focus 是否注册。
  6. data type:factions —— 检查 NPC 阵营定义是否注册。
  7. data copper_age:copper_clan —— 查看单条记录详情。
  8. list_recipes 1 20 prefix=copper_age: —— 检查配方是否注册。

说明

doctor_*、archive_*、snapshot_* 这些命令主要给引擎维护者用。普通 MOD 作者一般不需要关心它们。
