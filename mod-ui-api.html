UI 框架

通过 Lua 注册底边栏按钮、浮动提示和样式，不需要直接操作 ImGui。引擎统一调度渲染，Lua 只负责声明和回调。

设计思路

  • 所有 Lua UI API 挂在 engine.ui 全局表下。
  • Lua 注册 UI 内容，引擎负责渲染。Lua 不持有 ImGui 指针。
  • 注册 API 返回正整数句柄（失败时返回 0），方便后续更新、隐藏和注销。
  • 同一 id 重复注册会覆盖旧定义，适合脚本热重载。
  • 回调中的错误不会中断游戏循环——引擎记录日志并跳过本帧对应 UI。

命名空间

UI API 分为三个子命名空间：

命名空间用途
engine.ui.bottom_bar屏幕底部的常驻工具栏按钮、状态指示器
engine.ui.floating浮动提示、屏幕消息、教程提示和告警
engine.ui.style样式枚举（severity 等）

通用字段

所有可注册 UI 共享以下字段：

字段类型必填默认值说明
idstring是无全局唯一稳定 ID，建议 mod_id:name
priorityinteger否0渲染排序，值越大越靠前
visibleboolean / function否true是否显示；函数返回 boolean
enabledboolean / function否true是否可交互；函数返回 boolean
tooltipstring / function否nil鼠标悬停提示
on_clickfunction否nil点击回调

回调上下文

on_click 回调接收一个上下文表 ctx：

{
    id = "core:jobs",
    handle = 12,
    tick = 12345,
    dt = 0.016,
    hovered = true,
    active = false
}

底边栏 API

底边栏用于注册屏幕底部的常驻工具、状态按钮和模式切换入口。引擎负责布局，Lua 只提供按钮/文本/状态。

注册槽位

engine.ui.bottom_bar.register_slot(def) —— 注册一个底边栏槽位，成功返回句柄，失败返回 0。

local handle = engine.ui.bottom_bar.register_slot({
    id = "core:build_menu",
    priority = 100,
    kind = "button",
    icon = "hammer",
    label = "建造",
    tooltip = "打开建造菜单",
    hotkey = "B",
    on_click = function(ctx)
        engine.events.emit("ui:build_menu:toggle", { source = ctx.id })
    end
})

除通用字段外，槽位还支持以下字段：

字段类型必填默认值说明
kindstring否"button""button"、"toggle"、"label"、"meter"
labelstring / function否""显示文本
iconstring / function否nil图标 ID；初版可只显示文本
hotkeystring否nil仅作 UI 提示显示；实际输入走输入系统
valuenumber / functionmeter 必填nilmeter 当前值，范围 0..1
activeboolean / functiontoggle 推荐falsetoggle 是否处于激活状态
badgestring / number / function否nil角标，如任务数量

更新槽位

engine.ui.bottom_bar.update_slot(handle_or_id, patch) —— 局部更新已注册槽位。返回 true 或 false。

engine.ui.bottom_bar.update_slot("core:jobs", {
    badge = 5,
    tooltip = "当前有 5 个待处理工作"
})

注销槽位

engine.ui.bottom_bar.unregister_slot(handle_or_id) —— 注销底边栏槽位。返回 true 或 false。

engine.ui.bottom_bar.unregister_slot("core:build_menu")

批量清理

engine.ui.bottom_bar.clear(mod_id) —— 清理指定 MOD 注册的所有底边栏槽位。留空时只允许 debug/dev 场景清理全部。

engine.ui.bottom_bar.clear("core")

浮动提示 API

浮动提示用于短生命周期的世界提示、屏幕提示、教程提示和告警。支持屏幕坐标（固定位置）和世界坐标（跟随世界实体投影到屏幕）两种模式。

注册常驻锚点

engine.ui.floating.register_anchor(def) —— 注册可重复使用的浮动提示锚点，适合常驻的实体状态提示、选中对象提示。

local anchor = engine.ui.floating.register_anchor({
    id = "core:selected_block_hint",
    mode = "screen",
    x = function() return 24 end,
    y = function() return 92 end,
    visible = function()
        return engine.selection and engine.selection.has_block and engine.selection.has_block()
    end,
    render = function(ctx)
        return {
            title = "方块",
            body = "左键选择，右键取消",
            severity = "info"
        }
    end
})

锚点特有字段：

字段类型必填默认值说明
modestring否"screen""screen" 或 "world"
xnumber / functionscreen 必填0屏幕 X
ynumber / functionscreen 必填0屏幕 Y
world_xnumber / functionworld 必填0世界 X
world_ynumber / functionworld 必填0世界 Y
world_znumber / functionworld 必填0世界 Z
offset_xnumber否0屏幕偏移 X
offset_ynumber否0屏幕偏移 Y
ttl_ticksinteger否00 表示常驻，正数表示自动过期 tick 数
renderfunction否nil返回提示内容表的函数

render 函数返回值

render(ctx) 返回一个描述提示内容的表：

{
    title = "库存已满",
    body = "殖民者无法继续搬运。",
    icon = "warning",
    severity = "warning",   -- info | success | warning | error
    progress = 0.35,        -- 可选，0..1 进度条
    actions = {             -- 可选，初版可先不实现按钮
        { id = "open_jobs", label = "查看工作" }
    }
}

显示一次性提示

engine.ui.floating.show(def) —— 显示一次性浮动提示，适合教程和短消息。字段与锚点基本一致，但可直接提供 title/body 等字段，无需 render 函数。

engine.ui.floating.show({
    id = "core:first_colonist_tip",
    mode = "screen",
    x = 24,
    y = 120,
    title = "殖民者已抵达",
    body = "为他安排采矿、搬运或建造工作。",
    severity = "success",
    ttl_ticks = engine.time.tps * 6
})

更新提示

engine.ui.floating.update(handle_or_id, patch) —— 更新常驻锚点或一次性提示。

engine.ui.floating.update("core:first_colonist_tip", {
    body = "选择一个方块开始建造。",
    severity = "info"
})

关闭提示

engine.ui.floating.dismiss(handle_or_id) —— 关闭指定提示。

engine.ui.floating.dismiss("core:first_colonist_tip")

样式枚举

初版只提供有限的 severity 枚举，不要在 Lua 中直接操作 ImGui 样式栈。

engine.ui.style.severity = {
    info = "info",
    success = "success",
    warning = "warning",
    error = "error"
}
severity渲染映射
info普通提示，蓝/灰色调
success成功反馈，绿色调
warning可恢复问题，黄色调
error失败或阻塞问题，红色调

生命周期与调用时机

  1. on_load —— 注册静态底边栏槽位（按钮、toggle 等）。
  2. on_world_init —— 注册依赖世界状态的浮动锚点。
  3. 引擎每帧 UI 阶段调用渲染系统，Lua 函数字段被求值。
  4. 引擎每 tick 清理过期的 ttl_ticks 提示。
  5. 热重载或 MOD 卸载时调用 clear(mod_id)。
注册 UI 的时机要和生命周期配合：bottom_bar 在 on_load 注册，floating 锚点在 on_world_init 注册。一次性提示可以在任何时机调用 floating.show。

完整示例

以下是一个 MOD 注册底边栏和浮动提示的完整示例：

local M = {}

local jobs_badge = 0

function M.on_load()
    -- 底边栏：工作按钮
    engine.ui.bottom_bar.register_slot({
        id = "core:jobs",
        priority = 90,
        kind = "button",
        icon = "briefcase",
        label = "工作",
        badge = function() return jobs_badge end,
        tooltip = function()
            return "待处理工作：" .. tostring(jobs_badge)
        end,
        on_click = function()
            engine.events.emit("ui:jobs:toggle", {})
        end
    })

    -- 底边栏：暂停/继续切换
    engine.ui.bottom_bar.register_slot({
        id = "core:speed",
        priority = 10,
        kind = "toggle",
        label = "暂停",
        active = function()
            return engine.simulation and engine.simulation.paused and engine.simulation.paused()
        end,
        on_click = function()
            engine.events.emit("simulation:pause:toggle", {})
        end
    })
end

function M.on_world_init()
    -- 欢迎提示，8 秒后自动消失
    engine.ui.floating.show({
        id = "core:welcome_tip",
        mode = "screen",
        x = 24,
        y = 96,
        title = "欢迎来到 NewColony",
        body = "使用底边栏打开工作和建造界面。",
        severity = "info",
        ttl_ticks = engine.time.tps * 8
    })
end

function M.on_tick(tick, dt)
    if tick % 20 == 0 then
        -- 实际实现后应从工作系统读取
        jobs_badge = jobs_badge
    end
end

return M

C++ 实现备注

这部分面向引擎开发者，MOD 作者通常不需要关心。

  • 建议新增模块 Engine/UI/LuaUi.hpp 和 Engine/UI/LuaUi.cpp。
  • Lua 函数字段保存为 sol::object 或 sol::protected_function，每帧求值时必须使用 protected call。
  • 句柄由 UI 系统统一分配，使用递增 u64。
  • 以 id -> handle 建索引，重复注册同一 id 时替换旧项。
  • 渲染排序：按 priority 降序，同优先级按注册顺序升序。
  • clear(mod_id) 删除指定 MOD 的所有注册项。
  • 初版只渲染文本按钮、文本角标和普通 tooltip；图标字段先保留。

验收标准

检查项说明
注册底边栏按钮通过 register_slot 添加按钮并可见
创建浮动提示通过 floating.show 创建带 TTL 的屏幕提示
中文文本显示中文文本从 Lua 传入并正确渲染
去重重复注册相同 id 不产生重复 UI
错误隔离Lua 回调报错只记录日志，不导致崩溃
热重载清理MOD 热重载后调用 clear(mod_id) 可清除旧 UI
