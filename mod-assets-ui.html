UI 图片资源

MOD 可以通过 mod.json 的 ui 字段声明客户端 UI 图片。当前已支持主菜单背景图和背景图片池。

文件位置

UI 图片推荐放在 assets/ui/ 下。当前只支持 PNG，路径必须相对 MOD 根目录，不能使用绝对路径或 .. 跳出 MOD 目录。

my_theme/
  mod.json
  assets/
    ui/
      background001.png
      background002.png

声明图片和图片池

images 是图片 ID 到 PNG 路径的映射。image_pools 是图片池，池成员可以引用 images 中的 ID，也可以直接写 PNG 相对路径。

{
  "id": "my_theme",
  "side": "client",
  "ui": {
    "images": {
      "main_menu_background_001": "assets/ui/background001.png",
      "main_menu_background_002": "assets/ui/background002.png"
    },
    "image_pools": {
      "main_menu_backgrounds": [
        "main_menu_background_001",
        "main_menu_background_002"
      ]
    }
  }
}

主菜单背景

主菜单从 ui.main_menu.background_pool 指定的图片池中选择背景。当前选择策略只支持 "first"，也就是使用池中的第一张图片。

{
  "ui": {
    "images": {
      "main_menu_background_001": "assets/ui/background001.png"
    },
    "image_pools": {
      "main_menu_backgrounds": ["main_menu_background_001"]
    },
    "main_menu": {
      "background_pool": "main_menu_backgrounds",
      "selection": "first",
      "background_tint": [0.0, 0.0, 0.0, 0.35]
    }
  }
}
字段类型说明
ui.imagesobject图片 ID 到 PNG 路径的映射。
ui.image_poolsobject图片池。每个池是字符串数组。
ui.main_menu.background_poolstring主菜单背景使用的图片池 ID。
ui.main_menu.background_imagestring不使用图片池时的单张图片 ID 或 PNG 路径。
ui.main_menu.selectionstring当前只支持 "first"。
ui.main_menu.background_tintarray覆盖在背景上的 RGBA 遮罩，四个数值范围为 0 到 1。

多个 MOD 的合并规则

同名 image_pools 会按 MOD 加载顺序合并。CoreMod 默认最早加载，因此 core 放入 main_menu_backgrounds 的图片会排在池子前面；后加载的 MOD 可以向同名池追加更多背景图。

ui.main_menu 的配置本身仍按加载顺序覆盖，最后一个声明主菜单背景配置的 MOD 决定使用哪个池、哪种选择策略和遮罩颜色。当前选择策略只支持 "first"，因此会使用合并后池子的第一张可用 PNG。

UI 图片资源是客户端表现资源，不参与方块纹理图集。不要把全屏 UI 背景放进 assets/textures/block/。

RML/RCSS 文档资源（RmlUI 入口）

游戏内 RmlUI 的文档资源放在 <core_assets>/ui/rml/（即 CoreMod/assets/ui/rml/）。这是当前正式玩家可见 UI 资源目录，与 ui.images 图片资源相互独立，不进方块纹理图集。

CoreMod/assets/ui/rml/
├── main.rml      # 入口文档（RmlUiHost 默认加载 main.rml）
└── main.rcss     # main.rml 链接的 RCSS 样式

main.rml 是游戏内 UI 入口文档，不是浏览器网页布局。默认玩家构建由 RealRmlUiRuntime 加载并渲染；Null stub 只在显式诊断/失败回退路径下存在，不实际加载文档。HUD 的右上角时间条由 hud.rml/hud.rcss 渲染，并包含 core:time.speed 的 1x/2x/3x/Max 模拟速度按钮。依赖状态、CMake option、stub/真 backend 边界见 游戏内 RmlUI。

字体：CoreMod 和发行包不包含字体文件。真 backend 只加载操作系统的 Unicode 字体，并以统一的 Unicode 家族名提供给 RML/RCSS；缺少系统候选字体不会阻止启动。

加载与热重载

  • 入口：RmlUiHost::init() 默认加载 main.rml。
  • 热重载：页面发 core:rmlui.reload 命令，或开发期调用 engine.rml_ui().reload()。
  • 世界加载后 Host 触发 on_world_init() 重载页面并重推 world_info。
完整桥契约（C++ ↔ 文档的快照与命令）、生命周期、当前支持/未支持能力，见 UI 框架 · 游戏内 RmlUI 宿主层。
