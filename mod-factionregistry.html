NPC 阵营注册

NPC 阵营定义放在 data/factions/ 下，用 JSON 描述可生成的外部势力类型。阵营定义会进入 NpcFactionSystem，用于世界初始化时生成阵营实例、显示外交名称、维护关系值和触发外交事件。

JSON 格式

{
    "id": "my_mod:merchant_house",
    "name_template": {
        "en-us": "${random_name} Merchant House",
        "zh-cn": "${random_name}商馆"
    },
    "initial_relation": 15,
    "max_relation": 100,
    "min_relation": -60,
    "inclination": "commercial",
    "name_pools": ["core:generic"]
}

字段说明

字段类型必填说明
idstring是唯一标识，格式 <mod_id>:<name>。短 ID 会由加载器补成本 MOD 的完整 ID。
name_templatestring 或 object否阵营实例名称模板。可以直接写字符串，也可以写 locale 到模板的对象。模板中的 ${random_name} 会从 名称池中抽词替换。省略时使用 id 作为名称。
initial_relationint否生成实例时对玩家或其他系统的初始关系值，默认 0。读取后会被夹在 min_relation 和 max_relation 之间。
max_relationint否关系值上限，默认 100。
min_relationint否关系值下限，默认 -100。
inclinationstring否阵营倾向标签，默认 neutral。内置内容使用 warlike、pragmatic、commercial、raider、scholarly 等值；脚本和外交事件可以按该字符串分组。
name_poolsstring[]否可用于生成名称的名称池基础 ID，例如 core:generic。运行时会按当前 locale 选择 <pool_id>/<locale>，缺失时回退到 en-us 或任意可用池。

名称模板

name_template 支持两种写法。单字符串适合不做本地化的 MOD；对象形式适合每种界面语言使用不同语序或后缀。

{
    "name_template": "${random_name} Guild"
}

{
    "name_template": {
        "en-us": "${random_name} Guild",
        "zh-cn": "${random_name}公会"
    }
}

${random_name} 是阵营命名系统的占位符，不是通用本地化占位符。它只在生成阵营实例名称时被替换。

内置阵营

CoreMod 当前注册了 5 个阵营定义：

ID倾向初始关系范围用途
core:barbarian_tribewarlike-10-100 到 30偏敌对的部落势力。
core:mercenary_companypragmatic0-80 到 80中立雇佣兵势力。
core:merchant_guildcommercial20-50 到 100偏贸易的友好势力。
core:pirate_bandraider-30-100 到 50偏掠夺的敌对势力。
core:scholar_orderscholarly40-30 到 100偏研究的友好势力。

运行时行为

  • data/factions/ 注册的是阵营定义，不是已经存在于存档中的阵营实例。
  • 新世界启动时，阵营实例可由 spawn rule 或 Lua 调用生成；实例会保存显示名称、关系值、倾向和生成 tick。
  • 关系值修改会按该实例定义中的 min_relation / max_relation 夹取。
  • 外交事件可以比较两个阵营实例的 inclination，例如挑选倾向不同的势力对来改变关系。
  • 事件界面复用 data/focuses/。与阵营关系相关的事件可通过 Lua focus 条件触发，并在玩家选择详情操作时调用外交/贸易脚本。
data/faction_spawn_rules/ 也是加载器支持的数据目录，但它不在 mod-directory.html 列出的 17 个通用注册目录中。本页只覆盖 data/factions/；生成规则可通过控制台或 Lua 的 engine.factions.list_spawn_rules() 检查。

文件放置规则

  • 放在 data/factions/ 下，支持子目录。
  • 文件名随意，引擎只关心 JSON 内的 id 字段。
  • 引用其他 MOD 的名称池时写完整 ID，例如 other_mod:noble_houses。

验证命令

在控制台（按物理 Grave/反引号键）中确认阵营注册：

list_data factions              -- 列出所有已注册的 NPC 阵营定义
data core:merchant_guild        -- 查看单个阵营定义的完整 JSON
list_factions                   -- 查看运行时阵营定义和已生成实例
list_name_pools                 -- 查看名称池是否可用于命名
