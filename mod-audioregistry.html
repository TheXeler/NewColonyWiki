音频注册

data/audio/ 是标准自动注册目录。每个 .json 文件注册一个可播放声音定义，顶层 id 就是 Lua 和引擎播放接口使用的声音 ID；不再使用 sound bank / sounds[] 包装。

路径

CoreMod/data/audio/sfx_button_click.json
mods/my_mod/data/audio/ui/click.json

最小示例

{
  "id": "my_mod:sfx_click",
  "file": "assets/audio/effects/click.wav"
}

完整示例

{
  "id": "my_mod:bgm_title",
  "file": "assets/audio/music/title.ogg",
  "category": "music",
  "streaming": true,
  "loop": true,
  "volume": 0.7,
  "format": "ogg",
  "length_seconds": 96.5,
  "reload": false
}

字段

字段类型必填说明
idstring是音频数据 ID，也是 engine.audio.play(id) / engine.audio.play_3d(id) 使用的播放 ID。未带命名空间时按所属 MOD 解析。
filestring是音频文件路径。相对路径从 MOD 根目录解析，通常指向 assets/audio/。
categorystring否music、ambient、effect 或兼容别名 effects。默认 effect。
streamingbool否是否流式加载。长音乐和环境音建议设为 true。
loopbool否默认是否循环播放。
volumenumber否默认音量，范围 0.0 到 1.0，默认 1.0。
formatstring否资源格式元数据，例如 wav 或 ogg。当前用于校验/文档化，不覆盖底层解码器识别。
length_secondsnumber否音频长度元数据，单位秒，必须非负。引擎不会依赖该字段计算播放时长。
reloadbool否通用数据注册表热重载标记。

加载行为

  • ModLoader 像处理其他注册表一样扫描 data/audio/**/*.json，每个文件生成一个 type = "audio" 的注册项。
  • 音频系统在引擎初始化阶段读取这些注册项，并把每个条目注册为一个可播放声音。
  • 注册表格式已经去除 sound bank 外壳；旧版 sounds[] bank 仅保留为无注册项时的兼容回退，不应在新 MOD 中使用。
  • 如果多个 MOD 注册同一个音频 ID，通用数据注册表的覆盖/冲突规则与其他数据类型一致。

播放

local handle = engine.audio.play("my_mod:sfx_click")
engine.audio.play("my_mod:bgm_title", 1.0, true)
