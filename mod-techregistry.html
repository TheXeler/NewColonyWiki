科技注册

科技定义放在 data/techs/ 下。科技树当前支持分类、前置科技、研究成本、研究进度和开始研究命令/API。

JSON 格式

{
  "id": "core:crop_rotation",
  "name": "ui.core:tech.crop_rotation.name",
  "description": "ui.core:tech.crop_rotation.description",
  "category": "production",
  "research_ticks": 180,
  "prerequisites": [],
  "unlocks": ["recipe:core:wheat_farm", "building:core:matchbox_hut"]
}

字段说明

字段类型必填说明
idstring是唯一标识，格式 <mod_id>:<name>。
namestring否显示名称。可以直接写文本，也可以写 ui. 本地化 key。
descriptionstring否详情描述。科技界面会在详情区显示。
categorystring是科技分类。可选值：production、building、combat、diplomacy、trade。
research_ticksuint否研究成本。文明实例更新时按 tick 推进进度，默认 100。
prerequisitesstring[]否前置科技 ID。全部已研究后才允许开始研究。
unlocksstring[]否解锁内容 ID。building:<id> 控制建筑蓝图可下单状态，recipe:<id> 控制制造配方可制造状态；无前缀字符串仍作为展示型 unlock 保留。

Lua API

engine.research.list_techs()
engine.research.categories()
engine.research.list_by_category("production")
engine.research.get_tech("core:crop_rotation")
engine.research.state(1)
engine.research.can_research("core:crop_rotation", 1)
engine.research.start("core:crop_rotation", 1)

engine.techs 是 engine.research 的别名。

控制台命令

list_data techs
list_techs
research_start core:crop_rotation

RmlUI 数据桥

RmlUI 文档可以读取 tech_tree 快照通道。该通道固定返回 production、building、combat、diplomacy、trade 五类，每个节点包含 id、name、description、category、prerequisites、cost、progress、status 和 unlocks。

NC.snapshot("tech_tree")
NC.sendCommand("core:research.start", { nodeId: "core:crop_rotation" })

core:research.start 进入真实研究系统，返回 { ok, reason? }，并广播 ui:data:changed；开始研究和完成研究都会刷新 tech_tree、build_defs 和 craft_recipes。

当前实际 unlock

第一批实际接入范围很小：未研究对应科技时，RmlUI 快照会把目标项标记为 status: "locked"，并返回 locked_by。

科技影响目标快照字段
core:timber_framing建筑 core:matchbox_hutbuild_defs[].can_order=false，locked_by="core:timber_framing"
core:militia_drills配方 core:wooden_sword、core:bowcraft_recipes[].can_craft=false，locked_by="core:militia_drills"
CoreMod 默认提供生产、建筑、战斗、外交、贸易五个分类各一条基础科技。UI 详情会展示成本、前置、进度和 unlocks；当前只有上表列出的建筑/配方 unlock 会影响下单状态，其它 unlock 仍为展示和后续系统接入数据。
