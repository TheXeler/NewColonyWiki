名称池注册

名称池定义在 data/name_pools/ 下，只提供本地化名称词汇。它不会自行创建其他殖民地、改变关系或推进外交事件。

目录与 JSON

data/name_pools/
  settlement/
    en-us.json
    zh-cn.json
{
  "id": "my_mod:settlement",
  "words": ["North", "River"]
}
字段类型必填说明
iddata id是基础池 ID；同一基础 ID 可按语言提供多个文件。
wordsstring[]是非空词汇数组；空字符串会被忽略，最终无可用词时该文件不注册。

语言选择

文件名表示语言代码。查询显式名称池时，引擎优先使用当前语言版本，其次使用 en-us，最后使用该基础池已有的任一语言版本。模板中的 ${random_name} 会从明确传入的名称池抽取词汇；模板不含占位符时保持原文。显式池全部缺失时不会改用其他已注册池；招募候选生成会以 candidate_name_pool_missing 阻止。

CoreMod 状态

CoreMod 当前注册 core:generic 的 en-us 与 zh-cn 词汇文件，供需要显示候选人姓名的接口使用。CoreMod 不提供 NPC 阵营定义、阵营生成规则或外交提案；名称池存在不代表这些玩法已定义。

接口与诊断

  • engine.factions.list_name_pools()：列出已注册的语言变体。
  • engine.factions.generate_name(template, pool_ids, seed)：按显式模板、池列表和种子生成显示名称。
  • data type:name_pools / list_name_pools：在开发者控制台检查注册结果。

其他殖民地的实例生成、关系范围、外交周期和提案效果没有专项设计时保持接口未定；名称池不会为这些缺失规则提供默认值。
