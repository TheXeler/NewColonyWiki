名称池注册

名称池（Name Pool）定义在 data/name_pools/ 下，以 JSON 描述。名称池提供随机命名素材，NPC 阵营在实例化时从中抽取词语生成随机名称。名称池支持多语言——按语言子目录组织，引擎根据当前语言自动选择对应的词池。

JSON 格式

每个语言版本的名称池放在以基础池 ID 命名的子目录下，文件名为语言代码：

data/name_pools/
  viking/
    en-us.json
    zh-cn.json

每个文件格式：

{
    "id": "my_mod:viking",
    "words": [
        "Ragnar", "Bjorn", "Erik", "Sigurd", "Harald",
        "Longship", "Shield", "Axe", "Fjord", "Saga"
    ]
}

字段说明

字段类型必填说明
idstring是基础标识，格式 <mod_id>:<name>。同一 id 可有多个语言版本。
wordsstring[]是该语言的词汇列表。阵营从列表中随机抽取一个或多个词拼接为名称。
词汇数量没有上限，但建议保持 20~100 个以保证命名多样性。词汇越少，生成名称的重复率越高。

多语言支持

名称池按语言子目录组织。文件名（去掉 .json）即为语言代码（如 en-us、zh-cn）。引擎内部将基础池 ID 与语言代码组合为 pool_id/locale 作为唯一标识。

示例目录结构：

data/name_pools/
  generic/
    en-us.json    → {"id": "core:generic", "words": ["Iron", "Stone", ...]}
    zh-cn.json    → {"id": "core:generic", "words": ["铁", "石", ...]}
  viking/
    en-us.json    → {"id": "my_mod:viking", "words": ["Ragnar", "Bjorn", ...]}
    zh-cn.json    → {"id": "my_mod:viking", "words": ["拉格纳", "比约恩", ...]}

阵营定义中的 name_pools 引用基础池 ID（不带语言后缀），引擎根据当前语言自动解析：

{
    "id": "my_mod:viking_clan",
    "name_template": {
        "en-us": "${random_name} Clan",
        "zh-cn": "${random_name}部落"
    },
    "name_pools": ["my_mod:viking"]
}

语言解析规则

生成名称时，引擎按以下顺序查找词池：

  1. pool_id/current_locale — 精确匹配当前语言
  2. pool_id/en-us — 回退到英语
  3. 任意以 pool_id/ 开头的池 — 取第一个
  4. 所有池 — 最终回退

name_template 多语言格式

name_template 支持两种格式：

  • 字符串（向后兼容）："name_template": "${random_name} Clan"
  • 对象（多语言）："name_template": {"en-us": "${random_name} Clan", "zh-cn": "${random_name}部落"}

使用对象格式时，引擎根据当前语言选择对应模板；找不到则回退到第一个条目。

与阵营的关系

名称池被 NPC 阵营（data/factions/）引用。阵营定义中的 name_template 字段使用 ${random_name} 占位符，name_pools 字段指定引用哪些名称池（使用基础 ID）：

{
    "id": "my_mod:viking_clan",
    "name_template": {
        "en-us": "${random_name} Clan",
        "zh-cn": "${random_name}部落"
    },
    "initial_relation": 0,
    "max_relation": 50,
    "min_relation": -80,
    "inclination": "warlike",
    "name_pools": ["my_mod:viking"]
}

引擎在实例化阵营时，根据当前语言从对应词池中收集词汇，随机选取一个替换每个 ${random_name}，生成如"Ironhide Clan"（英语）或"铁皮部落"（中文）这样的名称。

使用案例

案例 1：单池单占位符

最基础的用法：一个阵营引用一个名称池，模板中有一个 ${random_name}。

名称池（英语） data/name_pools/viking/en-us.json：

{
    "id": "my_mod:viking",
    "words": ["Ragnar", "Bjorn", "Erik", "Sigurd", "Fjord", "Shield", "Axe"]
}

名称池（中文） data/name_pools/viking/zh-cn.json：

{
    "id": "my_mod:viking",
    "words": ["拉格纳", "比约恩", "埃里克", "西格德", "峡湾", "盾", "斧"]
}

阵营 data/factions/viking_clan.json：

{
    "id": "my_mod:viking_clan",
    "name_template": {
        "en-us": "${random_name} Clan",
        "zh-cn": "${random_name}部落"
    },
    "initial_relation": -10,
    "max_relation": 30,
    "min_relation": -100,
    "inclination": "warlike",
    "name_pools": ["my_mod:viking"]
}

生成结果（英语）："Ragnar Clan"、"Shield Clan"……

生成结果（中文）："拉格纳部落"、"盾部落"……

案例 2：多池合并

一个阵营可以引用多个名称池，引擎会将所有池的词汇合并后再随机选取。

名称池 A data/name_pools/colors/en-us.json：

{
    "id": "my_mod:colors",
    "words": ["Crimson", "Azure", "Golden", "Silver", "Obsidian"]
}

名称池 B data/name_pools/animals/en-us.json：

{
    "id": "my_mod:animals",
    "words": ["Wolf", "Eagle", "Dragon", "Serpent", "Phoenix"]
}

阵营 data/factions/beast_clan.json：

{
    "id": "my_mod:beast_clan",
    "name_template": {
        "en-us": "${random_name} Clan",
        "zh-cn": "${random_name}氏族"
    },
    "initial_relation": 0,
    "max_relation": 60,
    "min_relation": -60,
    "inclination": "neutral",
    "name_pools": ["my_mod:colors", "my_mod:animals"]
}

生成结果：从 colors + animals 共 10 个词中随机选，可能是 "Crimson Clan"、"Dragon Clan"、"Golden Clan"等。

案例 3：多重占位符

模板中可以使用多个 ${random_name}，每次独立抽取（允许重复）。

{
    "id": "my_mod:ancient_order",
    "name_template": "The ${random_name} ${random_name}",
    "initial_relation": 20,
    "max_relation": 100,
    "min_relation": -30,
    "inclination": "commercial",
    "name_pools": ["core:generic"]
}

生成结果："The Iron Wolf"、"The Storm Eagle"、"The Silver Silver"（可能重复）等。使用大池（如 core:generic 约 400 词）可以显著降低重复率。

案例 4：使用 CoreMod 通用池

不想创建自定义名称池时，可以直接引用内置的 core:generic。CoreMod 的所有阵营都这样做：

{
    "id": "core:merchant_guild",
    "name_template": {
        "en-us": "${random_name} Merchant Guild",
        "zh-cn": "${random_name}商会"
    },
    "initial_relation": 20,
    "max_relation": 100,
    "min_relation": -50,
    "inclination": "commercial",
    "name_pools": ["core:generic"]
}

生成结果（英语）："Ironhide Merchant Guild"……

生成结果（中文）："铁皮商会"、"唤风暴商会"等。

名称生成规则

  • ${random_name} 是唯一的占位符，大小写敏感。
  • 每个 ${random_name} 独立从合并后的词汇池中随机抽取，多次出现可能抽到同一个词。
  • 引擎根据当前语言优先选择对应语言的词池，找不到时回退到 en-us，再回退到任意可用池。
  • 如果 name_pools 中引用的基础池 ID 不存在（没有任何语言版本），该池被跳过；如果所有池都不存在，引擎回退使用当前语言的所有已注册名称池。
  • 如果模板中没有 ${random_name}，名称就是模板原文（静态名称）。
  • 每个阵营实例的名称不同——同一个阵营定义被多次实例化时，每次独立生成。

内置名称池

CoreMod 注册了 1 个通用名称池，提供英语和中文两个语言版本：

通用 core:generic

包含约 400 个词汇，涵盖自然、金属、颜色、动物、地形、职业等类别。所有未指定专用名称池的阵营默认使用此名称池。

语言版本：en-us（英文词）、zh-cn（中文词）

词汇分类示例（英文）：

类别示例词汇
金属/材质Iron, Copper, Bronze, Steel, Obsidian, Onyx
颜色Crimson, Azure, Violet, Amber, Scarlet, Cobalt
动物Wolf, Eagle, Raven, Dragon, Phoenix, Serpent
地形Ridge, Hollow, Vale, Glen, Summit, Canyon
建筑Fortress, Citadel, Tower, Bastion, Spire
职业Smith, Weaver, Mason, Brewer, Fletcher, Cooper
复合词Ironhide, Stormcaller, Moonshadow, Firebrand

文件放置规则

  • 放在 data/name_pools/ 下，按基础池 ID 创建子目录，每个语言一个 JSON 文件。
  • 文件名（去掉 .json）即为语言代码，如 en-us.json、zh-cn.json。
  • JSON 内的 id 字段为基础池 ID，同一 ID 可以有多个语言版本。
  • 引擎会自动扫描子目录中的所有 JSON 文件。

验证命令

在控制台（按物理 Grave/反引号键）中确认名称池注册：

list_name_pools                   -- 列出所有已注册的名称池（含语言变体）
list_factions                     -- 列出所有阵营定义
spawn_faction core:barbarian_tribe -- 实例化一个阵营，观察生成的名称
