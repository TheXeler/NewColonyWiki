MOD 示例：本地化名称池

这个示例只演示清单、Lua 生命周期和本地化名称池，不发明方块产出、配方、文明、要闻、战斗或外交规则。

目录

name_sample/
  mod.json
  scripts/bootstrap.lua
  data/name_pools/settlement/en-us.json
  data/name_pools/settlement/zh-cn.json

mod.json

{
  "id": "name_sample",
  "name": "Name Sample",
  "version": "1.0.0",
  "entry": "scripts/bootstrap.lua",
  "dependencies": []
}

入口脚本

local M = {}

function M.on_load()
  engine.log.info("[name_sample] loaded")
end

return M

名称池

{
  "id": "name_sample:settlement",
  "words": ["North", "River"]
}
{
  "id": "name_sample:settlement",
  "words": ["北", "河"]
}

边界

名称池只提供显示词汇，不会自动创建其他殖民地。需要加入物品、建筑、配方、生态、天气或其他玩法时，必须使用对应页面列出的现行 schema；NCDOCS 没有定义的公式、概率、形状、周期和默认内容不能从旧示例复制。
