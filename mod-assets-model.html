模型格式

方块模型使用 Blockbench JSON 格式，兼容 Minecraft 基岩版方块模型规范。模型文件与纹理 PNG 放在同一目录下。

支持的格式

格式扩展名说明
Blockbench JSON.json兼容 Minecraft 基岩版方块模型格式。由 Blockbench 编辑器导出。
推荐使用 Blockbench 编辑器创建和导出模型。Blockbench 可直接生成兼容的 JSON 格式，并实时预览 UV 映射效果。

目录放置

模型 JSON 和对应的纹理 PNG 放在 assets/textures/block/ 的同一子目录下：

assets/textures/block/NewColonyTextures/
  grass.png                  -- 纹理图（64×64）
  grass.json                 -- Blockbench 模型定义
  lantern.png                -- 纹理图
  lantern.json               -- Blockbench 模型定义

模型 JSON 结构

{
    "format_version": "1.21.11",
    "credit": "Made with Blockbench",
    "texture_size": [64, 64],
    "textures": {
        "0": "my_texture"
    },
    "elements": [
        {
            "from": [0, 0, 0],
            "to": [16, 16, 16],
            "rotation": {"angle": 0, "axis": "y", "origin": [8, 8, 8]},
            "faces": {
                "north": {"uv": [0, 0, 4, 4], "texture": "#0"},
                "east":  {"uv": [0, 4, 4, 8], "texture": "#0"},
                "south": {"uv": [4, 0, 8, 4], "texture": "#0"},
                "west":  {"uv": [4, 4, 8, 8], "texture": "#0"},
                "up":    {"uv": [4, 12, 0, 8], "texture": "#0"},
                "down":  {"uv": [12, 0, 8, 4], "texture": "#0"}
            }
        }
    ]
}

字段说明

字段类型说明
format_versionstring模型格式版本，当前为 "1.21.11"。
texture_size[int, int]纹理图尺寸（像素），如 [64, 64]。UV 坐标基于此尺寸计算。标准方块为 [16, 16]。
texturesobject纹理引用表。键为纹理 ID（如 "0"、"13"），值为 PNG 文件名（不含扩展名）。
elementsarray模型元素数组。每个元素是一个长方体。一个模型可以有多个元素组成复杂形状。

元素字段

字段类型说明
from[float × 3]长方体最小角坐标，范围 0~16（方块像素单位）。
to[float × 3]长方体最大角坐标，范围 0~16。
rotationobject旋转参数。angle 必须是 90 的整数倍（0/90/180/270），axis 为 "x"/"y"/"z"，origin 为旋转中心坐标。
facesobject六个面的 UV 和纹理引用。

面方向

方向名朝向
north-Z
south+Z
east+X
west-X
up+Y
down-Y

面字段

字段类型说明
uv[float × 4]UV 坐标 [u0, v0, u1, v1]，以 texture_size 为基准的像素坐标。例如 texture_size 为 64 时，[0, 0, 4, 4] 表示纹理图左上角 4×4 像素区域。
texturestring纹理引用，格式 "#纹理ID"（如 "#0"）。指向 textures 表中的条目。

示例：多元素灯笼模型

灯笼由底座、灯柱、灯罩和火焰多个元素组成，每个元素有独立的 from/to 和 UV：

{
    "format_version": "1.21.11",
    "textures": {
        "13": "lantern_texture"
    },
    "elements": [
        {
            "from": [6.9, 1.45, 6.9],
            "to": [9.1, 1.75, 9.1],
            "rotation": {"angle": 0, "axis": "y", "origin": [5, 1, 5]},
            "faces": {
                "north": {"uv": [9, 12, 11, 12.5], "texture": "#13"},
                "east":  {"uv": [11, 12, 13, 12.5], "texture": "#13"},
                "south": {"uv": [12, 11, 14, 11.5], "texture": "#13"},
                "west":  {"uv": [7, 13, 9, 13.5], "texture": "#13"},
                "up":    {"uv": [9, 9, 7, 7], "texture": "#13"},
                "down":  {"uv": [5, 8, 3, 10], "texture": "#13"}
            }
        },
        {
            "from": [7, 1.75, 7],
            "to": [9, 5, 9],
            "rotation": {"angle": 0, "axis": "y", "origin": [5, 1, 5]},
            "faces": {
                "north": {"uv": [3, 0, 5, 3.5], "texture": "#13"},
                "east":  {"uv": [3, 4, 5, 7.5], "texture": "#13"},
                "south": {"uv": [5, 0, 7, 3.5], "texture": "#13"},
                "west":  {"uv": [5, 4, 7, 7.5], "texture": "#13"},
                "up":    {"uv": [7, 10, 5, 8], "texture": "#13"},
                "down":  {"uv": [2, 9, 0, 11], "texture": "#13"}
            }
        }
    ]
}
