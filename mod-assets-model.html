方块模型格式

世界方块和地面物品使用 Minecraft Java 版烘焙模型 JSON 语义。实体仍使用独立的 glTF 模型。

完整字段、默认值、必填标记、UV 公式和算法见 docs/minecraft-java-block-model-technical-reference.md。“必填”严格对应上游页面的星号标记；可选字段缺失时不得报错。

目录与预处理

方块模型放在 assets/models/block/<name>.json，物品形态放在 assets/models/item/<name>.json；两类模型都在启动时预处理。纹理使用相对 assets/textures/ 的命名空间资源 ID。只处理启用中的 MOD。缓存只有一种当前格式；签名不匹配时直接重建，不读取旧结构。

物品形态与植被

minecraft:item/generated 和 minecraft:item/handheld 为虚拟父模型，支持 layer0 至 layer4。从 PNG alpha 生成前后面和外露像素轮廓的侧面，厚度为一个模型像素；透明区域不变成立方体面，相邻不透明像素不生成内部侧面。手持父模型目前提供相同的生成几何，不解析 Minecraft 的视角 display 变换。显式 elements 可覆盖生成形态。

{
  "parent": "minecraft:item/handheld",
  "textures": {"layer0": "core:items/test_sword"}
}

物品模型单独登记，不覆盖世界方块的材质或形状。地面物品优先使用同名 item 模型；没有 item 模型的方块保留 block 形状，独立物品的 icon 可作为生成 sprite 的来源。minecraft:block/cross 提供 Minecraft 的两张旋转交叉片，适合浆果丛等植被。测试食物在世界中使用浆果丛模型，掉落后使用浆果图标生成的物品模型；测试铁剑使用 handheld 模型。

树苗 core:sapling 在世界中使用 block/cross 与透明橡树苗贴图，图标和 item/generated 掉落物引用同一张贴图。其 block_class: "transparent" 使角色可以穿过，也不遮挡相邻面；渲染形状和通行属性分开配置。树苗仍是可命中的体素方块，不是 ECS 实体。当前射线选中按整格判断，尚未实现 Minecraft 的较小树苗选中框。

小麦阶段模型 wheat_stage0 至 wheat_stage7 继承本地 core:block/wheat_crop_template，使用四张双面竖片与各自阶段贴图；与树苗的两张对角交叉片不同。耕地模型为 15/16 格高，小麦竖片从模型 Y=-1 开始，与耕地顶面对齐。小麦及种子物品采用 item/generated。

方块物品缺少独立 item 模型时保留 block 模型或立方体兜底，只有独立物品的图标自动生成薄片。木板使用 wood_plank.json 与橡木木板贴图，物品堆中保持立方体。树叶在程序化兜底之前加载 leaves.json 与 oak_leaves.png；其 tintindex 从 MC foliage 色表按默认温度 0.5、降雨 1.0 的坐标采样，并用于完整模型、LOD 和地面方块物品（这里的 0.5 是 MC 色表自身的 0-1 坐标，与引擎的摄氏度气候温度无关）。当前尚未接入群落颜色混合或树叶腐烂。

烟熏炉 core:smoker 使用显式六面立方体模型，北面为炉口，顶面、底面与侧面分别引用 smoker_top、smoker_bottom 和 smoker_side；四张贴图从工作区已有素材导入。其 item 模型继承 core:block/smoker，地面物品保留炉体形状。独立面包物品 core:bread 使用 minecraft:item/generated 与 textures/items/bread.png。

建筑工作点的 working_visuals 可在加工时显示动画表面及烟火粒子。烟熏炉炉口引用 16x48 的 smoker_front_on.png，按三帧每帧 0.2 秒循环显示；烟雾与火焰为独立摄像机朝向四边形，8 像素火焰图会最近邻放大到 16 像素。静态模型中的 textures.particle 只定义纹理变量，不产生粒子。工作点效果显式声明帧时间，不读取 Minecraft 的 .mcmeta；它也不改变方块模型几何或 ID。完整配置见建筑数据。

根字段

字段类型必填缺省行为
parentstring否无父模型
ambientocclusionbool否继承；根模型为 true
texturesobject否与父表合并；根模型为空
elementsarray否继承；根模型为空

纹理变量

"textures": {
  "base": "core:block/stone",
  "particle": "#base",
  "glass": {
    "sprite": "core:block/glass",
    "force_translucent": true
  }
}

字符串可以是纹理资源 ID 或 #变量。对象形式中的 sprite 条件必填，force_translucent 可选且默认为 false。父子变量合并后再解析别名。

元素字段

字段类型必填缺省行为
from3-number array是无；每轴范围 [-16,32]
to3-number array是无；每轴范围 [-16,32]
rotationobject否不旋转
shadebool否true
light_emissionint否0，范围 [0,15]
facesobject是允许空对象

from 与 to 的先后顺序具有法线、面交换和 UV 语义，引擎不会擅自排序。坐标单位为方块的十六分之一。

元素旋转

rotation 出现时，三数值 origin 必填。单轴形式要求 axis 与 angle；多轴形式要求 x、y、z。两种形式同时出现时采用单轴形式。rescale 可选，默认为 false。

"rotation": {
  "origin": [8, 8, 8],
  "axis": "y",
  "angle": 22.5,
  "rescale": true
}

面字段

字段类型必填缺省行为
texturestring是必须为非空 #变量
uv4-number array否按元素坐标和面方向推导
rotationint否0；只接受 0、90、180、270
tintindexint否-1，即不着色
cullfacestring否不参与邻块剔除

面名为 up、down、north、south、west、east。UV 始终使用 0 到 16 的逻辑坐标，与 PNG 实际分辨率无关。

错误行为

JSON 类型错误、缺少条件必填字段、坐标越界、非法旋转、父链循环或父模型缺失会记录明确日志并编译为统一无效模型。纹理变量缺失、循环或 PNG 缺失只替换相应纹理。合法的空 elements 或空 faces 保持不渲染。
