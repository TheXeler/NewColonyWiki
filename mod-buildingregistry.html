建筑蓝图注册

建筑是 MOD 数据，放在 data/buildings/ 下，由 ModLoader 自动注册并交给 BuildingSystem 初始化。建造菜单列出建筑蓝图，施工完成后按蓝图把方块放入世界。

基础结构

{
  "id": "my_mod:watch_hut",
  "name": "Watch Hut",
  "name_key": "buildings.my_mod:watch_hut",
  "size": [5, 5, 5],
  "materials": [
    { "item_id": "core:wood_plank", "count": 72 },
    { "item_id": "core:wooden_door", "count": 1 }
  ],
  "construction_ticks": 240,
  "blueprint": [
    { "from": [0, 0, 0], "to": [4, 0, 4], "block": "core:wood_floor" },
    { "from": [0, 1, 0], "to": [4, 3, 0], "block": "core:wood" },
    { "pos": [2, 1, 0], "block": "core:wooden_door" }
  ]
}

字段

字段说明
id建筑 ID。省略命名空间时会解析到当前 MOD。
name_key本地化 key，例如 buildings.my_mod:watch_hut。UI 可优先用它查翻译；没有翻译时回退到 name。
name建造菜单显示名称；没有本地化文本时使用。
size必填。蓝图包围盒，格式为 [x, y, z]，每项必须为正整数。
materials必填数组。施工开始前需要从库存取出的材料列表，item_id 必须是有效数据 ID，count 必须为正整数。
construction_ticks必填正整数。施工耗时，20 tick 约等于 1 秒。
blueprint可选的方块放置列表。没有蓝图的建筑仍可作为逻辑建筑存在。

蓝图单元

blueprint 中每个元素都需要 block。可以用 pos 放置单个方块，也可以用 from/to 描述闭区间长方体。

{ "pos": [2, 1, 0], "block": "core:wooden_door" }
{ "from": [0, 0, 0], "to": [4, 0, 4], "block": "core:wood_floor" }

所有坐标都是相对于建筑原点的偏移，必须落在 size 范围内。from 的每个坐标必须小于或等于 to。block 必须引用已注册的 data/blocks/ 条目。

内置示例

CoreMod/data/buildings/matchbox_hut.json 提供了一个木头火柴盒小屋示例，展示地板、墙体、屋顶和门的组合写法。
